# M1 Engine (`@tysiac/engine`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `packages/engine`, a pure, dependency-free TypeScript package that implements every Tysiąc house rule (spec §3) as a deterministic reducer with per-player views, bots, and a coach, proven by ported tests and a ≥ 2,000-game bot simulation.

**Architecture:** All game state is one JSON-serializable `GameState`. `reduce(state, playerId, action, now)` deep-clones the state, validates the action against `legalActions`, applies it through small phase handlers (`src/phases/*.ts`) and returns the new state plus `GameEvent`s tagged with an `audience`. Pure rule modules (`cards`, `tricks`, `bidding`, `scoring`, `wykladana`, `deal`, `rng`) hold the logic ported from `apps/server`; `viewFor` and `eventsFor` are the only way information leaves the engine. Bots (`src/bot`) and the coach (`src/coach`) see only a `PlayerView`.

**Tech Stack:** TypeScript 5 (strict, ESM, `moduleResolution: bundler`), Vitest 4, pnpm 9 workspace, Node 24. Zero runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-09-tysiac-rebuild-design.md` (§3 rules are authoritative, §4 engine API, §9 coach, §10 testing). Original code being ported: `apps/server/src/game/{validation,scoring,wykladana,engine}.ts`, `apps/server/src/game/phases/*.ts`, `apps/server/src/ai/index.ts`, `packages/shared/src/types/{cards,game}.ts`.

## Global Constraints

- Package: `packages/engine`, name `@tysiac/engine`, `"type": "module"`, **zero runtime `dependencies`** (only `devDependencies`: `typescript`, `vitest`).
- TypeScript `strict: true`; `tsc --noEmit` must pass for `src` and `test`.
- No I/O, no `Date.now()`, no `Math.random()` anywhere in `packages/engine/src` (time is passed as `now`; randomness comes from the seeded RNG string in `GameState.rng` or an injected `rng` function).
- `GameState` must survive `JSON.parse(JSON.stringify(state))` unchanged — no `Map`, `Set`, `undefined`-valued fields that matter, class instances or functions.
- `reduce` is deterministic given `(state, playerId, action, now)`, never mutates its input, never throws on malformed client input (returns `{ ok: false, error }`).
- Rules numbers come from the single `RULES` object in `src/rules.ts`: deck 9,10,J,Q,K,A × ♣♦♥♠; points A11 10:10 K4 Q3 J2 9:0 (120/round); strength A>10>K>Q>J>9; marriages ♥100 ♦80 ♣60 ♠40; auto-bid 100, step 10, max bid 120 + marriages; redeal below 18 points without a marriage; barrel 800–999; win at 1000; rounding: remainder ≥ 6 rounds up; 4-player sitting-out dealer +50 per talon ace.
- Only the **first player to respond after the leader** must beat the lead card if able; bids are exactly current + 10 or pass; bidder needs raw points ≥ bid (rounding never helps) and then scores `roundToTen(raw)`; no barrel attempt limit; leading a Q while holding its K auto-declares the marriage and makes that suit trump for the current trick.
- Dealer for round `n` is `seats[(firstDealer + n − 1) % seats.length]` (round numbers include throw-redeals).
- Events carry an `audience` (`'all'` or a list of player ids); hidden information (hands, a private talon, other players' hand-out cards) is only ever sent to the players allowed to see it.
- Coach text: short, friendly English; suits always as symbols ♥♦♣♠ (never the words hearts/diamonds/clubs/spades).
- Commands: `pnpm --filter @tysiac/engine test` (vitest run), `pnpm --filter @tysiac/engine typecheck` (tsc). Run from the repo root `/Users/filip/Code/tysiac-game`.
- Commit messages end with the line `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. **Malformed or hostile actions** (`null`, unknown `type`, `card` missing/garbage, `bid.amount` as a string, `handout.to` null or with extra keys, a non-seated player id) — `reduce` must return `{ ok: false }` with a sensible code and never throw or mutate. Test: Task 7 "rejects malformed actions without throwing".
2. **Hidden information leaking through events** (a `dealt` hand, a private talon at 100, the other defender's hand-out card) — `eventsFor` must only return each player's own copy. Test: Task 9 "events never leak hidden cards".
3. **Pause in the middle of a trick and resume by a different player** — every engine action except `resume` is rejected while paused, any seated player may resume, and play continues exactly where it stopped. Test: Task 7 "pause mid-trick blocks play until anyone resumes".
4. **Repeated throw-ins at 100** — each throw must advance the round number and dealer, leave scores untouched, and record a `thrown` summary; the game must never get stuck. Test: Task 7 "repeated throws at 100 keep rotating the dealer".
5. **State persisted as JSON between actions** (the Durable Object stores state as one JSON value) — a game whose state is JSON round-tripped after every action must finish identically to one that is not. Test: Task 12 "is deterministic and survives JSON round-trips".

```ts
import type { Card, Rank, Suit } from './types';
import { RANKS, RULES, SUITS, SUIT_SYMBOL } from './rules';

const SUIT_LETTER: Record<Suit, string> = { clubs: 'C', diamonds: 'D', hearts: 'H', spades: 'S' };
const LETTER_SUIT: Record<string, Suit> = { C: 'clubs', D: 'diamonds', H: 'hearts', S: 'spades' };

export function createDeck(): Card[] {
  const deck: Card[] = [];
  for (const suit of SUITS) for (const rank of RANKS) deck.push({ suit, rank });
  return deck;
}

export function cardEquals(a: Card, b: Card): boolean {
  return a.suit === b.suit && a.rank === b.rank;
}

/** Compact id, e.g. '10D', 'QH'. */
export function cardKey(card: Card): string {
  return `${card.rank}${SUIT_LETTER[card.suit]}`;
}

/** Parses 'KD', '10h', '9S' (rank + suit letter, case-insensitive). Throws on bad input. */
export function parseCard(text: string): Card {
  const m = /^(9|10|J|Q|K|A)([CDHS])$/i.exec(text.trim());
  if (!m) throw new Error(`Bad card: ${text}`);
  return { rank: m[1].toUpperCase() as Rank, suit: LETTER_SUIT[m[2].toUpperCase()] };
}

/** Parses a space-separated list: 'KH QH 9S'. Empty string → []. */
export function parseCards(text: string): Card[] {
  return text.split(/\s+/).filter(Boolean).map(parseCard);
}

/** Human label with suit symbol, e.g. 'K♦'. */
export function cardLabel(card: Card): string {
  return `${card.rank}${SUIT_SYMBOL[card.suit]}`;
}

export function cardPoints(card: Card): number {
  return RULES.cardPoints[card.rank];
}

export function handPoints(cards: readonly Card[]): number {
  return cards.reduce((sum, c) => sum + cardPoints(c), 0);
}

export function hasMarriage(hand: readonly Card[], suit: Suit): boolean {
  const hasQueen = hand.some(c => c.suit === suit && c.rank === 'Q');
  const hasKing = hand.some(c => c.suit === suit && c.rank === 'K');
  return hasQueen && hasKing;
}

/** Suits with K+Q in hand, in ♥♦♣♠ order (highest value first). */
export function marriagesInHand(hand: readonly Card[]): Suit[] {
  return RULES.marriageOrder.filter(suit => hasMarriage(hand, suit));
}

export function totalMarriageValue(hand: readonly Card[]): number {
  return marriagesInHand(hand).reduce((sum, suit) => sum + RULES.marriageValues[suit], 0);
}

/** Returns a new hand without `card`. Throws if the card is not in the hand. */
export function removeCard(hand: readonly Card[], card: Card): Card[] {
  const i = hand.findIndex(c => cardEquals(c, card));
  if (i < 0) throw new Error(`Card ${cardKey(card)} not in hand`);
  return [...hand.slice(0, i), ...hand.slice(i + 1)];
}

/** Runtime guard for untrusted input. */
export function isCard(x: unknown): x is Card {
  if (!x || typeof x !== 'object') return false;
  const c = x as { suit?: unknown; rank?: unknown };
  return SUITS.includes(c.suit as Suit) && RANKS.includes(c.rank as Rank);
}
```

```ts
import type { Card, PlayerId, Suit, TrickCard } from './types';
import { RULES, SUIT_SYMBOL } from './rules';
import { cardEquals, cardLabel, hasMarriage } from './cards';

/**
 * Card play rules for Polish Tysiąc:
 * - All players must follow suit if they can
 * - The FIRST player to respond after the leader must beat the lead card if possible
 * - The remaining player has no obligation to beat — just follow suit
 * - If you can't follow suit, any card is valid (no obligation to trump)
 */

export interface ValidationResult {
  isValid: boolean;
  reason?: string;
}

const STRENGTH = RULES.rankStrength;

export function canBeat(card: Card, toBeat: Card, _leadSuit: Suit, trumpSuit: Suit | null): boolean {
  if (trumpSuit) {
    if (card.suit === trumpSuit && toBeat.suit !== trumpSuit) return true;
    if (card.suit !== trumpSuit && toBeat.suit === trumpSuit) return false;
    if (card.suit === trumpSuit && toBeat.suit === trumpSuit) {
      return STRENGTH[card.rank] > STRENGTH[toBeat.rank];
    }
  }
  if (card.suit !== toBeat.suit) return false;
  return STRENGTH[card.rank] > STRENGTH[toBeat.rank];
}

export function getHighestCardInTrick(cards: Card[], leadSuit: Suit, trumpSuit: Suit | null): Card {
  let highest = cards[0];
  for (let i = 1; i < cards.length; i++) {
    const card = cards[i];
    if (trumpSuit) {
      if (card.suit === trumpSuit && highest.suit !== trumpSuit) {
        highest = card;
        continue;
      }
      if (card.suit !== trumpSuit && highest.suit === trumpSuit) continue;
      if (card.suit === trumpSuit && highest.suit === trumpSuit) {
        if (STRENGTH[card.rank] > STRENGTH[highest.rank]) highest = card;
        continue;
      }
    }
    if (card.suit === leadSuit && highest.suit === leadSuit) {
      if (STRENGTH[card.rank] > STRENGTH[highest.rank]) highest = card;
    }
  }
  return highest;
}

export interface TrickWinnerResult {
  winnerId: PlayerId;
  winningCard: Card;
  reason: string;
  /** A trump won a trick whose lead suit was not trump. */
  byTrump: boolean;
}

export function getTrickWinnerWithReason(trick: TrickCard[], trumpSuit: Suit | null): TrickWinnerResult {
  const leadSuit = trick[0].card.suit;
  const highestCard = getHighestCardInTrick(trick.map(t => t.card), leadSuit, trumpSuit);
  const winner = trick.find(t => cardEquals(t.card, highestCard))!;
  const isTrump = trumpSuit !== null && highestCard.suit === trumpSuit;
  const isLeadSuit = highestCard.suit === leadSuit;
  let reason: string;
  if (isTrump && !isLeadSuit) reason = `${cardLabel(highestCard)} won by trumping`;
  else if (isTrump && isLeadSuit) reason = `${cardLabel(highestCard)} won as highest trump (trump is lead suit)`;
  else reason = `${cardLabel(highestCard)} won as highest card in lead suit`;
  return { winnerId: winner.p, winningCard: highestCard, reason, byTrump: isTrump && !isLeadSuit };
}

export function getTrickWinner(trick: TrickCard[], trumpSuit: Suit | null): PlayerId {
  return getTrickWinnerWithReason(trick, trumpSuit).winnerId;
}

export function getValidCards(hand: Card[], trick: TrickCard[], trumpSuit: Suit | null): Card[] {
  if (trick.length === 0) return [...hand];
  const leadCard = trick[0].card;
  const leadSuit = leadCard.suit;
  const cardsInSuit = hand.filter(c => c.suit === leadSuit);
  if (cardsInSuit.length === 0) return [...hand];
  // Anyone after the first responder: just follow suit.
  if (trick.length >= 2) return cardsInSuit;
  // First responder: must beat the lead card if possible.
  const beating = cardsInSuit.filter(c => canBeat(c, leadCard, leadSuit, trumpSuit));
  return beating.length > 0 ? beating : cardsInSuit;
}

export function canDeclareMarriage(
  hand: Card[],
  suit: Suit,
  declaredMarriages: Suit[],
  isLeading: boolean,
): ValidationResult {
  if (!isLeading) return { isValid: false, reason: 'Can only declare marriage when leading a trick' };
  if (declaredMarriages.includes(suit)) return { isValid: false, reason: 'Marriage already declared' };
  if (!hasMarriage(hand, suit)) return { isValid: false, reason: 'No marriage in this suit' };
  return { isValid: true };
}

export function validateCardPlay(
  card: Card,
  hand: Card[],
  trick: TrickCard[],
  trumpSuit: Suit | null,
): ValidationResult {
  if (!hand.some(c => cardEquals(c, card))) return { isValid: false, reason: 'Card not in hand' };
  const valid = getValidCards(hand, trick, trumpSuit);
  if (!valid.some(c => cardEquals(c, card))) return { isValid: false, reason: 'Invalid card for current rules' };
  return { isValid: true };
}

/** Friendly reason why `card` cannot be played now, or null if it can. Agrees with getValidCards. */
export function cardRuleMessage(
  hand: Card[],
  trick: TrickCard[],
  trumpSuit: Suit | null,
  card: Card,
): string | null {
  if (!hand.some(c => cardEquals(c, card))) return "That card isn't in your hand";
  if (trick.length === 0) return null;
  const lead = trick[0].card;
  const inSuit = hand.filter(c => c.suit === lead.suit);
  if (inSuit.length > 0 && card.suit !== lead.suit) return `You must follow ${SUIT_SYMBOL[lead.suit]}`;
  if (trick.length === 1 && inSuit.length > 0) {
    const beating = inSuit.filter(c => canBeat(c, lead, lead.suit, trumpSuit));
    if (beating.length > 0 && !beating.some(c => cardEquals(c, card))) {
      return `First to respond must beat ${cardLabel(lead)} if you can`;
    }
  }
  return null;
}
```

```ts
import type { Card, PlayerId } from './types';
import { RULES } from './rules';
import { totalMarriageValue } from './cards';
import type { ValidationResult } from './tricks';

/** Max bid = 120 + total value of marriages in hand. */
export function maxBidFor(hand: Card[]): number {
  return RULES.maxBidBase + totalMarriageValue(hand);
}

/** Bids must be exactly currentBid + 10 and not above maxBidFor(hand). */
export function validateBid(amount: number, currentBid: number, hand: Card[]): ValidationResult {
  const requiredBid = currentBid + RULES.bidStep;
  if (amount !== requiredBid) {
    return { isValid: false, reason: `Bid must be exactly ${requiredBid} (current bid + 10)` };
  }
  const marriageValue = totalMarriageValue(hand);
  const maxBid = RULES.maxBidBase + marriageValue;
  if (amount > maxBid) {
    return { isValid: false, reason: `Maximum bid is ${maxBid} (120 + ${marriageValue} from marriages)` };
  }
  return { isValid: true };
}

/** Next active player clockwise after `current` who has not passed and is not the high bidder. */
export function nextBidder(
  active: PlayerId[],
  current: PlayerId,
  high: PlayerId,
  passed: PlayerId[],
): PlayerId | null {
  const start = active.indexOf(current);
  for (let k = 1; k <= active.length; k++) {
    const candidate = active[(start + k) % active.length];
    if (candidate !== high && !passed.includes(candidate)) return candidate;
  }
  return null;
}
```

```ts
import type { Card, PlayerId, PlayerRoundResult, RoundScoreResult, RoundSummary, Scores } from './types';
import { RULES } from './rules';
import { marriagesInHand } from './cards';

/** Round to nearest 10; remainder >= 6 rounds up (15 → 10, 16 → 20). */
export function roundToTen(points: number): number {
  const remainder = points % 10;
  return remainder >= RULES.roundUpFrom ? points - remainder + 10 : points - remainder;
}

/** On the barrel: 800 ≤ total < 1000. */
export function isOnBarrel(total: number): boolean {
  return total >= RULES.barrelAt && total < RULES.winAt;
}

export interface ScoringInput {
  /** All seats, clockwise. */
  order: PlayerId[];
  bidder: PlayerId;
  bid: number;
  dealer: PlayerId;
  /** 4 players: the dealer sits out. */
  sittingOut: PlayerId | null;
  /** Totals before this round. */
  totals: Record<PlayerId, number>;
  trickPoints: Record<PlayerId, number>;
  tricksTaken: Record<PlayerId, number>;
  /** Sum of declared marriage values (counted only if the player took a trick). */
  declaredMarriagePoints: Record<PlayerId, number>;
  /** Sitting-out dealer bonus: talon marriages + 50 per talon ace. */
  talonBonus: number;
}

/**
 * Scores a played round (spec §3.9–3.11).
 * - Bidder: made if raw (tricks + counted marriages) >= bid → +roundToTen(raw); else −bid.
 * - Defenders: +roundToTen(tricks + counted marriages); 0 on the barrel.
 * - Sitting-out dealer: +roundToTen(talon bonus); 0 on the barrel.
 */
export function scoreRound(input: ScoringInput): RoundScoreResult {
  const playerScores: PlayerRoundResult[] = input.order.map(id => {
    const isBidder = id === input.bidder;
    const sittingOut = id === input.sittingOut;
    const prev = input.totals[id] ?? 0;
    const wasOnBarrel = isOnBarrel(prev);
    const trickPoints = sittingOut ? 0 : input.trickPoints[id] ?? 0;
    const wonTrick = (input.tricksTaken[id] ?? 0) > 0;
    const marriagePoints = sittingOut
      ? input.talonBonus
      : wonTrick
        ? input.declaredMarriagePoints[id] ?? 0
        : 0;
    const totalRoundPoints = trickPoints + marriagePoints;
    let scoreChange: number;
    if (isBidder) scoreChange = totalRoundPoints >= input.bid ? roundToTen(totalRoundPoints) : -input.bid;
    else if (wasOnBarrel) scoreChange = 0;
    else scoreChange = roundToTen(totalRoundPoints);
    const newTotalScore = prev + scoreChange;
    return {
      playerId: id,
      trickPoints,
      marriagePoints,
      totalRoundPoints,
      scoreChange,
      newTotalScore,
      wasOnBarrel,
      fellOffBarrel: wasOnBarrel && newTotalScore < RULES.barrelAt,
      isDealer: id === input.dealer,
      sittingOut,
    };
  });
  const bidder = playerScores.find(p => p.playerId === input.bidder)!;
  return {
    bidderMadeBid: bidder.totalRoundPoints >= input.bid,
    playerScores,
    winner: pickWinner(totalsOf(playerScores), input.bidder, input.order),
  };
}

export interface ThrowInput {
  order: PlayerId[];
  dealer: PlayerId;
  bidder: PlayerId;
  bid: number;
  sittingOut: PlayerId | null;
  totals: Record<PlayerId, number>;
}

/** Throw-in: at 100 nothing changes; above 100 bidder −bid, other active players +⌊120/others⌋ unless on the barrel. */
export function scoreThrow(input: ThrowInput): RoundScoreResult {
  const others = input.order.filter(id => id !== input.bidder && id !== input.sittingOut);
  const share = Math.floor(RULES.throwPool / others.length);
  const playerScores: PlayerRoundResult[] = input.order.map(id => {
    const prev = input.totals[id] ?? 0;
    const wasOnBarrel = isOnBarrel(prev);
    let scoreChange = 0;
    if (input.bid > RULES.autoBid) {
      if (id === input.bidder) scoreChange = -input.bid;
      else if (others.includes(id) && !wasOnBarrel) scoreChange = share;
    }
    const newTotalScore = prev + scoreChange;
    return {
      playerId: id,
      trickPoints: 0,
      marriagePoints: 0,
      totalRoundPoints: 0,
      scoreChange,
      newTotalScore,
      wasOnBarrel,
      fellOffBarrel: wasOnBarrel && newTotalScore < RULES.barrelAt,
      isDealer: id === input.dealer,
      sittingOut: id === input.sittingOut,
    };
  });
  return {
    bidderMadeBid: false,
    playerScores,
    winner: pickWinner(totalsOf(playerScores), input.bidder, input.order),
  };
}

/** Anyone >= 1000 wins. Several: the bidder if among them, else highest total, else first clockwise from the bidder. */
export function pickWinner(totals: Record<PlayerId, number>, bidder: PlayerId, order: PlayerId[]): PlayerId | null {
  const reached = order.filter(id => (totals[id] ?? 0) >= RULES.winAt);
  if (reached.length === 0) return null;
  if (reached.includes(bidder)) return bidder;
  const best = Math.max(...reached.map(id => totals[id]));
  const start = order.indexOf(bidder);
  for (let k = 1; k <= order.length; k++) {
    const id = order[(start + k) % order.length];
    if (reached.includes(id) && totals[id] === best) return id;
  }
  return null;
}

export function applyScoreResult(scores: Scores, result: RoundScoreResult): Scores {
  const next: Scores = {};
  for (const [id, s] of Object.entries(scores)) next[id] = { total: s.total, history: [...s.history] };
  for (const p of result.playerScores) {
    const prev = next[p.playerId] ?? { total: 0, history: [] };
    next[p.playerId] = { total: p.newTotalScore, history: [...prev.history, p.scoreChange] };
  }
  return next;
}

export function summarizeRound(meta: Omit<RoundSummary, 'players'>, result: RoundScoreResult): RoundSummary {
  return { ...meta, players: result.playerScores.map(p => ({ ...p })) };
}

/** 4-player sitting-out dealer bonus: marriages in the talon + 50 per ace in the talon. */
export function talonBonus(talon: Card[]): number {
  const marriages = marriagesInHand(talon).reduce((sum, suit) => sum + RULES.marriageValues[suit], 0);
  const aces = talon.filter(c => c.rank === 'A').length;
  return marriages + aces * RULES.talonAcePoints;
}

function totalsOf(players: PlayerRoundResult[]): Record<PlayerId, number> {
  return Object.fromEntries(players.map(p => [p.playerId, p.newTotalScore]));
}
```

```ts
import type { Card, Suit } from './types';
import { hasMarriage } from './cards';
import { RULES } from './rules';

const RANK_ORDER = ['A', '10', 'K', 'Q', 'J', '9'];
const ALL_SUITS: readonly Suit[] = RULES.marriageOrder; // hearts, diamonds, clubs, spades

/**
 * Count consecutive top cards from Ace downward.
 * E.g. [A, 10, K, 9] → 3 (A, 10, K are consecutive; 9 breaks at Q).
 */
function getTopConsecutive(sortedCards: Card[]): number {
  for (let i = 0; i < sortedCards.length; i++) {
    if (sortedCards[i].rank !== RANK_ORDER[i]) return i;
  }
  return sortedCards.length;
}

/**
 * Check if the hand is a wykladana given a specific trump suit.
 *
 * Strategy: lead all trump first (highest→lowest) to exhaust opponent trumps,
 * then lead each off-suit (highest→lowest). A gap card (non-consecutive) wins
 * only if all opponent cards in that suit have already been forced out by
 * earlier top-consecutive leads.
 *
 * For trump suit: top_consecutive >= opponent_trump_count
 *   (ensures all opponent trumps are exhausted; remaining gap trumps win
 *    because opponents can only play off-suit which doesn't beat trump)
 *
 * For each non-trump suit with gap cards: top_consecutive >= opponent_count
 *   (ensures all opponent cards in that suit are exhausted before gap cards
 *    are played; gap cards then win by default since no one can follow suit
 *    and all trump is already gone)
 */
function isWykladanaWithTrump(
  suitCards: Map<Suit, { cards: Card[]; topConsecutive: number }>,
  trumpSuit: Suit | null,
): boolean {
  // Trump must be exhaustable
  if (trumpSuit) {
    const trump = suitCards.get(trumpSuit);
    if (!trump) return false;
    const oppTrumps = 6 - trump.cards.length;
    if (trump.topConsecutive < oppTrumps) return false;
  }

  // Check each non-trump suit
  for (const [suit, { cards, topConsecutive }] of suitCards) {
    if (suit === trumpSuit) continue;

    const opp = 6 - cards.length;
    const gapCards = cards.length - topConsecutive;

    // All cards are top-consecutive → every lead wins
    if (gapCards === 0) continue;

    // Gap cards exist → need to exhaust all opponent cards in this suit first
    if (topConsecutive < opp) return false;
  }

  return true;
}

/**
 * Detect if WYKLADANA condition is met — bidder can guarantee winning ALL 8 tricks.
 *
 * The bidder leads optimally: exhaust all opponent trumps first, then play
 * each off-suit from the top. A hand qualifies if:
 *
 * 1. For the trump suit (best marriage): the number of consecutive top cards
 *    from Ace down is ≥ the number of opponent trumps (6 − own count).
 *    This guarantees every trump lead wins AND opponent trumps are fully
 *    exhausted, so remaining gap trumps also win.
 *
 * 2. For every non-trump suit the bidder holds: if there are any gap cards
 *    (cards below a break in the sequence), the consecutive top count must
 *    be ≥ opponent cards in that suit. This forces out all opponent cards
 *    before the gap card is led. If all cards are consecutive from the top,
 *    every lead automatically wins.
 *
 * Rank order: A, 10, K, Q, J, 9
 *
 * Example: A♦ 10♦ K♦ Q♦  A♠ 10♠ K♠ 9♠  (trump = diamonds)
 *   Diamonds: 4 consecutive (A-10-K-Q), opp = 2 → 4 ≥ 2 ✓
 *   Spades:   3 consecutive (A-10-K), gap card 9♠, opp = 2 → 3 ≥ 2 ✓
 *   → WYKLADANA (lead 4 diamonds, then A♠ 10♠ K♠ exhaust Q♠ J♠, 9♠ wins)
 */
export function detectWykladana(hand: Card[]): boolean {
  if (hand.length !== 8) return false;

  // Group cards by suit and pre-compute stats
  const suitCards = new Map<Suit, { cards: Card[]; topConsecutive: number }>();
  for (const card of hand) {
    if (!suitCards.has(card.suit)) suitCards.set(card.suit, { cards: [], topConsecutive: 0 });
    suitCards.get(card.suit)!.cards.push(card);
  }
  for (const [, entry] of suitCards) {
    entry.cards.sort((a, b) => RANK_ORDER.indexOf(a.rank) - RANK_ORDER.indexOf(b.rank));
    entry.topConsecutive = getTopConsecutive(entry.cards);
  }

  // Find marriages in hand (possible trump suits); also try no-trump if no marriages
  const marriageSuits = ALL_SUITS.filter(s => hasMarriage(hand, s));
  const trumpOptions: (Suit | null)[] = marriageSuits.length > 0 ? marriageSuits : [null];

  return trumpOptions.some(trumpSuit => isWykladanaWithTrump(suitCards, trumpSuit));
}

/** Trump for a wykładana round: the first marriage found in ♥♦♣♠ order, or null. */
export function wykladanaTrump(hand: Card[]): Suit | null {
  return ALL_SUITS.find(s => hasMarriage(hand, s)) ?? null;
}
```

```ts
// Seeded PRNG (mulberry32) whose whole state is an 8-hex-char string, so it lives in GameState.

/** FNV-1a hash of the seed → initial state. */
export function seedState(seed: string): string {
  let h = 0x811c9dc5;
  for (let i = 0; i < seed.length; i++) {
    h ^= seed.charCodeAt(i);
    h = Math.imul(h, 0x01000193);
  }
  return toHex(h);
}

/** Returns [value in [0,1), next state]. */
export function nextRandom(state: string): [number, string] {
  let a = parseInt(state, 16) | 0;
  a = (a + 0x6d2b79f5) | 0;
  let t = Math.imul(a ^ (a >>> 15), 1 | a);
  t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
  const value = ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  return [value, toHex(a)];
}

/** Fisher–Yates shuffle; returns [shuffled copy, next state]. */
export function shuffle<T>(items: readonly T[], state: string): [T[], string] {
  const out = [...items];
  let s = state;
  for (let i = out.length - 1; i > 0; i--) {
    const [r, next] = nextRandom(s);
    s = next;
    const j = Math.floor(r * (i + 1));
    [out[i], out[j]] = [out[j], out[i]];
  }
  return [out, s];
}

/** Stateful convenience generator for bots and simulations. */
export function makeRandom(seed: string): () => number {
  let s = seedState(seed);
  return () => {
    const [v, next] = nextRandom(s);
    s = next;
    return v;
  };
}

function toHex(n: number): string {
  return (n >>> 0).toString(16).padStart(8, '0');
}
```

```ts
import type { Card, PlayerId } from './types';
import { RULES } from './rules';
import { createDeck, handPoints, marriagesInHand } from './cards';
import { shuffle } from './rng';

/** Round n's dealer: firstDealer for round 1, then the next seat clockwise each round. */
export function dealerIndexFor(firstDealer: number, roundNumber: number, seatCount: number): number {
  return (firstDealer + roundNumber - 1) % seatCount;
}

/** Players who play the round, clockwise from left of the dealer. 4 seats: the dealer sits out. */
export function activeFor(seatIds: PlayerId[], dealerIndex: number): PlayerId[] {
  const n = seatIds.length;
  const out: PlayerId[] = [];
  for (let i = 1; i <= n; i++) {
    const idx = (dealerIndex + i) % n;
    if (n === 4 && idx === dealerIndex) continue;
    out.push(seatIds[idx]);
  }
  return out;
}

/** A hand is playable with >= 18 points or any marriage. */
export function isHandValid(hand: Card[]): boolean {
  return handPoints(hand) >= RULES.redealBelow || marriagesInHand(hand).length > 0;
}

export interface Deal {
  hands: Record<PlayerId, Card[]>;
  talon: Card[];
  rng: string;
  redeals: number;
}

/** Shuffle and deal 7 to each active player + 3 to the talon; reshuffle while any hand is invalid. */
export function dealCards(rng: string, active: PlayerId[]): Deal {
  let state = rng;
  let redeals = 0;
  for (;;) {
    const [deck, next] = shuffle(createDeck(), state);
    state = next;
    const hands: Record<PlayerId, Card[]> = {};
    for (const p of active) hands[p] = [];
    const dealt = RULES.handSize * active.length;
    for (let i = 0; i < dealt; i++) hands[active[i % active.length]].push(deck[i]);
    const talon = deck.slice(dealt, dealt + RULES.talonSize);
    if (active.every(p => isHandValid(hands[p]))) return { hands, talon, rng: state, redeals };
    redeals++;
  }
}
```

```ts
  now: number;
```

```ts
import { RULES } from './rules';
import { activeFor, dealCards, dealerIndexFor } from './deal';
import { clone, emit, seatIds, type Ctx } from './ctx';

/** Deals round `number` and opens bidding: first active player holds 100, the next one bids. */
export function startRound(ctx: Ctx, number: number): void {
  const s = ctx.s;
  const ids = seatIds(s);
  const dealerIndex = dealerIndexFor(s.firstDealer, number, ids.length);
  const dealer = ids[dealerIndex];
  const active = activeFor(ids, dealerIndex);
  const deal = dealCards(s.rng, active);
  s.rng = deal.rng;
  const perActive = <T>(f: () => T): Record<PlayerId, T> => Object.fromEntries(active.map(p => [p, f()]));
  s.round = {
    number,
    dealer,
    active,
    hands: deal.hands,
    talon: deal.talon,
    talonPublic: false,
    bid: { high: active[0], amount: RULES.autoBid, turn: active[1], passed: [] },
    trump: null,
    marriages: perActive<Suit[]>(() => []),
    trick: { leader: active[0], cards: [] },
    tricksWon: perActive<Card[][]>(() => []),
    handoutGiven: null,
    lastTrick: null,
  };
  s.phase = 'bidding';
  for (const id of ids) {
    emit(ctx, { type: 'dealt', round: number, dealer, active: [...active], hand: clone(deal.hands[id] ?? []) }, [id]);
  }
}
```

```ts
import type { GameState, Seat } from './types';
import { seedState } from './rng';
import { startRound } from './round';

export interface CreateGameOptions {
  seed: string;
  /** Seats in clockwise order (chosen in the lobby). */
  seats: Seat[];
  maxPlayers: 3 | 4;
  /** Seat index of the round-1 dealer. */
  firstDealer: number;
}

/** Creates a game and deals round 1. Throws on invalid options (a room-level programming error). */
export function createGame(opts: CreateGameOptions): GameState {
  const { seats, maxPlayers, firstDealer } = opts;
  if (maxPlayers !== 3 && maxPlayers !== 4) throw new Error('maxPlayers must be 3 or 4');
  if (seats.length !== maxPlayers) throw new Error(`Expected ${maxPlayers} seats, got ${seats.length}`);
  const ids = seats.map(x => x.id);
  if (new Set(ids).size !== ids.length) throw new Error('Seat ids must be unique');
  if (!Number.isInteger(firstDealer) || firstDealer < 0 || firstDealer >= maxPlayers) {
    throw new Error('firstDealer must be a seat index');
  }
  const s: GameState = {
    v: 1,
    seq: 0,
    rng: seedState(opts.seed),
    seats: seats.map(x => ({ ...x })),
    firstDealer,
    maxPlayers,
    phase: 'bidding',
    round: null,
    scores: Object.fromEntries(ids.map(id => [id, { total: 0, history: [] }])),
    rounds: [],
    paused: null,
    winner: null,
  };
  startRound({ s, events: [], now: 0 }, 1);
  return s;
}
```

```ts
export interface Scenario {
  seats?: Seat[];
  /** Default: last seat, so 3p active = [a, b, c] and 4p active = [a, b, c] with d sitting out. */
  dealer?: PlayerId;
  phase: Phase;
  hands: Record<PlayerId, string>;
  talon?: string;
  talonPublic?: boolean;
  bid?: Partial<BidState>;
  trump?: Suit | null;
  marriages?: Record<PlayerId, Suit[]>;
  trick?: { leader: PlayerId; cards: Array<[PlayerId, string]> };
  /** Each string is one won trick, e.g. 'AS 10S KS'. */
  tricksWon?: Record<PlayerId, string[]>;
  totals?: Record<PlayerId, number>;
  handoutGiven?: Record<PlayerId, string>;
  roundNumber?: number;
}

/** Builds a GameState at an arbitrary point of a round. Card conservation is NOT enforced. */
export function scenario(sc: Scenario): GameState {
  const seats = sc.seats ?? SEATS3;
  const ids = seats.map(s => s.id);
  const n = ids.length;
  const dealer = sc.dealer ?? ids[n - 1];
  const dealerIndex = ids.indexOf(dealer);
  const active = activeFor(ids, dealerIndex);
  const number = sc.roundNumber ?? 1;
  const high = sc.bid?.high ?? active[0];
  const bid: BidState = {
    high,
    amount: sc.bid?.amount ?? 100,
    turn: sc.bid?.turn !== undefined ? sc.bid.turn : sc.phase === 'bidding' ? active[1] : null,
    passed: sc.bid?.passed ?? [],
  };
  return {
    v: 1,
    seq: 0,
    rng: seedState('scenario'),
    seats: seats.map(s => ({ ...s })),
    firstDealer: (((dealerIndex - (number - 1)) % n) + n) % n,
    maxPlayers: n as 3 | 4,
    phase: sc.phase,
    round: {
      number,
      dealer,
      active,
      hands: Object.fromEntries(active.map(p => [p, parseCards(sc.hands[p] ?? '')])),
      talon: parseCards(sc.talon ?? ''),
      talonPublic: sc.talonPublic ?? false,
      bid,
      trump: sc.trump ?? null,
      marriages: Object.fromEntries(active.map(p => [p, [...(sc.marriages?.[p] ?? [])]])),
      trick: {
        leader: sc.trick?.leader ?? high,
        cards: (sc.trick?.cards ?? []).map(([p, card]) => ({ p, card: parseCard(card) })),
      },
      tricksWon: Object.fromEntries(active.map(p => [p, (sc.tricksWon?.[p] ?? []).map(t => parseCards(t))])),
      handoutGiven: sc.handoutGiven
        ? Object.fromEntries(Object.entries(sc.handoutGiven).map(([p, card]) => [p, parseCard(card)]))
        : null,
      lastTrick: null,
    },
    scores: Object.fromEntries(ids.map(id => [id, { total: sc.totals?.[id] ?? 0, history: [] }])),
    rounds: [],
    paused: null,
    winner: null,
  };
}
```

```ts
import type { Action, Card, GameState, PlayerId, Round } from './types';
import { RULES } from './rules';
import { cardEquals, isCard } from './cards';
import { maxBidFor } from './bidding';
import { getValidCards } from './tricks';

export function nextActive(active: readonly PlayerId[], p: PlayerId): PlayerId {
  const i = active.indexOf(p);
  return active[(i + 1) % active.length];
}

/** Who must act now (ignores pause), or null when the game is over. */
export function turnOf(s: GameState): PlayerId | null {
  const r = s.round;
  if (!r) return null;
  switch (s.phase) {
    case 'bidding':
      return r.bid.turn;
    case 'decision':
    case 'handout':
      return r.bid.high;
    case 'tricks': {
      const cards = r.trick.cards;
      return cards.length === 0 ? r.trick.leader : nextActive(r.active, cards[cards.length - 1].p);
    }
    default:
      return null;
  }
}

export function legalActions(s: GameState, p: PlayerId): Action[] {
  const r = s.round;
  if (!r || s.phase === 'gameEnd' || !s.seats.some(x => x.id === p)) return [];
  if (s.paused) return [{ type: 'resume' }];
  const out: Action[] = turnOf(s) === p ? phaseActions(s, r, p) : [];
  out.push({ type: 'pause' });
  return out;
}

function phaseActions(s: GameState, r: Round, p: PlayerId): Action[] {
  switch (s.phase) {
    case 'bidding': {
      const next = r.bid.amount + RULES.bidStep;
      const acts: Action[] = [];
      if (next <= maxBidFor(r.hands[p])) acts.push({ type: 'bid', amount: next });
      acts.push({ type: 'pass' });
      return acts;
    }
    case 'decision':
      return [{ type: 'play' }, { type: 'throw' }];
    case 'handout':
      return handoutOptions(r.hands[p], r.active.filter(q => q !== p));
    case 'tricks':
      return getValidCards(r.hands[p], r.trick.cards, r.trump).map(card => ({ type: 'card', card: { ...card } }));
    default:
      return [];
  }
}

/** Every way to give one distinct card to each of the two recipients. */
export function handoutOptions(hand: Card[], recipients: PlayerId[]): Action[] {
  const [x, y] = recipients;
  const out: Action[] = [];
  for (const c1 of hand) {
    for (const c2 of hand) {
      if (cardEquals(c1, c2)) continue;
      out.push({ type: 'handout', to: { [x]: { ...c1 }, [y]: { ...c2 } } });
    }
  }
  return out;
}

/** Structural equality of a known-good action `a` with untrusted input `b`. */
export function actionsEqual(a: Action, b: unknown): boolean {
  if (!b || typeof b !== 'object') return false;
  const o = b as Record<string, unknown>;
  if (o.type !== a.type) return false;
  switch (a.type) {
    case 'bid':
      return o.amount === a.amount;
    case 'card':
      return isCard(o.card) && cardEquals(a.card, o.card);
    case 'handout': {
      const to = o.to;
      if (!to || typeof to !== 'object') return false;
      const given = to as Record<string, unknown>;
      const keys = Object.keys(a.to);
      return (
        Object.keys(given).length === keys.length &&
        keys.every(k => {
          const x = given[k];
          return isCard(x) && cardEquals(a.to[k], x);
        })
      );
    }
    default:
      return true;
  }
}
```

```ts
/** Applies a round result, records it, emits `event`, then ends the game or deals the next round. */
export function concludeRound(
  ctx: Ctx,
  result: RoundScoreResult,
  summary: RoundSummary,
  event: GameEventBody,
): void {
  const s = ctx.s;
  s.scores = applyScoreResult(s.scores, result);
  s.rounds.push(summary);
  emit(ctx, event);
  if (result.winner) {
    s.phase = 'gameEnd';
    s.winner = result.winner;
    emit(ctx, { type: 'gameWon', p: result.winner, totals: totalsOf(s) });
    return;
  }
  startRound(ctx, summary.number + 1);
}
```

```ts
import type { PlayerId } from '../types';
import { RULES } from '../rules';
import { nextBidder } from '../bidding';
import { clone, emit, roundOf, type Ctx } from '../ctx';

export function applyBid(ctx: Ctx, p: PlayerId, amount: number): void {
  const r = roundOf(ctx);
  r.bid.high = p;
  r.bid.amount = amount;
  emit(ctx, { type: 'bid', p, amount });
  advance(ctx, p);
}

export function applyPass(ctx: Ctx, p: PlayerId): void {
  const r = roundOf(ctx);
  r.bid.passed.push(p);
  emit(ctx, { type: 'passed', p });
  advance(ctx, p);
}

function advance(ctx: Ctx, current: PlayerId): void {
  const r = roundOf(ctx);
  const next = r.bid.passed.length >= 2 ? null : nextBidder(r.active, current, r.bid.high, r.bid.passed);
  if (next) {
    r.bid.turn = next;
    return;
  }
  endBidding(ctx);
}

/** Bidding over: the talon goes into the winner's hand; everyone sees it only if the bid is > 100. */
function endBidding(ctx: Ctx): void {
  const r = roundOf(ctx);
  const high = r.bid.high;
  r.bid.turn = null;
  r.talonPublic = r.bid.amount > RULES.autoBid;
  r.hands[high] = [...r.hands[high], ...clone(r.talon)];
  ctx.s.phase = 'decision';
  emit(ctx, { type: 'biddingWon', p: high, amount: r.bid.amount, talonPublic: r.talonPublic });
  emit(ctx, { type: 'talonRevealed', p: high, cards: clone(r.talon) }, r.talonPublic ? 'all' : [high]);
}
```

```ts
import type { Action, GameState, PlayerId, ReduceResult, RuleError, RuleErrorCode } from './types';
import { actionsEqual, legalActions, turnOf } from './actions';
import { isCard } from './cards';
import { validateBid } from './bidding';
import { cardRuleMessage } from './tricks';
import { clone, emit, type Ctx } from './ctx';
import { applyBid, applyPass } from './phases/bidding';
import { applyPlay, applyThrow } from './phases/decision';

const err = (code: RuleErrorCode, message: string): RuleError => ({ code, message });
const fail = (error: RuleError): ReduceResult => ({ ok: false, error });

/**
 * Applies one action atomically. Pure and deterministic: same (state, playerId, action, now) → same result.
 * Rejects anything not in legalActions(state, playerId). Never throws on malformed input.
 */
export function reduce(state: GameState, playerId: PlayerId, action: Action, now: number): ReduceResult {
  if (!action || typeof action !== 'object' || typeof (action as { type?: unknown }).type !== 'string') {
    return fail(err('illegalAction', 'Unknown action'));
  }
  if (!state.seats.some(x => x.id === playerId)) return fail(err('notSeated', "You're not seated in this game"));
  if (state.phase === 'gameEnd') return fail(err('gameOver', 'The game is over'));
  if (state.paused && action.type !== 'resume') return fail(err('paused', 'The game is paused'));

  const legal = legalActions(state, playerId).find(a => actionsEqual(a, action));
  if (!legal) return fail(rejectFor(state, playerId, action));

  const ctx: Ctx = { s: clone(state), events: [], now };
  switch (legal.type) {
    case 'bid':
      applyBid(ctx, playerId, legal.amount);
      break;
    case 'pass':
      applyPass(ctx, playerId);
      break;
    case 'play':
      applyPlay(ctx);
      break;
    case 'throw':
      applyThrow(ctx, playerId);
      break;
    case 'pause':
      ctx.s.paused = { by: playerId, at: now };
      emit(ctx, { type: 'paused', p: playerId });
      break;
    case 'resume':
      ctx.s.paused = null;
      emit(ctx, { type: 'resumed', p: playerId });
      break;
    default:
      return fail(err('illegalAction', "That move isn't allowed right now"));
  }
  ctx.s.seq += 1;
  return { ok: true, state: ctx.s, events: ctx.events };
}

function rejectFor(s: GameState, p: PlayerId, action: Action): RuleError {
  if (action.type === 'resume') return err('illegalAction', "The game isn't paused");
  if (action.type === 'pause') return err('illegalAction', "You can't pause right now");
  const r = s.round;
  if (!r || turnOf(s) !== p) return err('notYourTurn', "It's not your turn");
  if (action.type === 'card' && s.phase === 'tricks') {
    const msg = isCard(action.card) ? cardRuleMessage(r.hands[p], r.trick.cards, r.trump, action.card) : null;
    return err('illegalCard', msg ?? "You can't play that card");
  }
  if (action.type === 'bid' && s.phase === 'bidding') {
    const amount = typeof action.amount === 'number' ? action.amount : NaN;
    return err('badBid', validateBid(amount, r.bid.amount, r.hands[p]).reason ?? 'Invalid bid');
  }
  if (action.type === 'handout' && s.phase === 'handout') {
    return err('badHandout', 'Give exactly one of your cards to each opponent');
  }
  return err('illegalAction', "That move isn't allowed right now");
}
```

```ts
export function finishRound(ctx: Ctx, wykladana: boolean): void {
  const s = ctx.s;
  const r = roundOf(ctx);
  const bidder = r.bid.high;
  const trickPoints: Record<PlayerId, number> = {};
  const tricksTaken: Record<PlayerId, number> = {};
  const declared: Record<PlayerId, number> = {};
  for (const p of r.active) {
    trickPoints[p] = r.tricksWon[p].reduce((sum, t) => sum + handPoints(t), 0);
    tricksTaken[p] = r.tricksWon[p].length;
    declared[p] = r.marriages[p].reduce((sum, suit) => sum + RULES.marriageValues[suit], 0);
  }
  if (wykladana) {
    trickPoints[bidder] = RULES.pointsPerRound;
    tricksTaken[bidder] = RULES.tricksPerRound;
  }
  const result = scoreRound({
    order: seatIds(s),
    bidder,
    bid: r.bid.amount,
    dealer: r.dealer,
    sittingOut: sittingOutOf(s),
    totals: totalsOf(s),
    trickPoints,
    tricksTaken,
    declaredMarriagePoints: declared,
    talonBonus: talonBonus(r.talon),
  });
  const summary = summarizeRound(
    {
      number: r.number,
      dealer: r.dealer,
      bidder,
      bid: r.bid.amount,
      outcome: result.bidderMadeBid ? 'made' : 'failed',
      wykladana,
    },
    result,
  );
```

```ts
import type { Card, PlayerId } from '../types';
import { marriagesInHand, removeCard } from '../cards';
import { detectWykladana } from '../wykladana';
import { clone, emit, roundOf, seatIds, type Ctx } from '../ctx';

export function applyHandout(ctx: Ctx, p: PlayerId, to: Record<PlayerId, Card>): void {
  const r = roundOf(ctx);
  let hand = r.hands[p];
  for (const [q, card] of Object.entries(to)) {
    hand = removeCard(hand, card);
    r.hands[q] = [...r.hands[q], { ...card }];
  }
  r.hands[p] = hand;
  r.handoutGiven = clone(to);
  const recipients = r.active.filter(q => q !== p);
  for (const id of seatIds(ctx.s)) {
    const cards: Partial<Record<PlayerId, Card>> = id === p ? clone(to) : to[id] ? { [id]: { ...to[id] } } : {};
    emit(ctx, { type: 'handedOut', p, recipients, cards }, [id]);
  }

  if (detectWykladana(hand)) {
    const marriages = marriagesInHand(hand);
    r.marriages[p] = marriages;
    r.trump = marriages[0] ?? null;
    emit(ctx, { type: 'wykladana', p, hand: clone(hand), trump: r.trump, marriages: [...marriages] });
    finishRound(ctx, true);
    return;
  }

  ctx.s.phase = 'tricks';
  r.trick = { leader: p, cards: [] };
}
```

```ts
import type { Card, PlayerId } from '../types';
import { RULES } from '../rules';
import { handPoints, hasMarriage, removeCard } from '../cards';
import { getTrickWinnerWithReason } from '../tricks';
import { clone, emit, roundOf, type Ctx } from '../ctx';
import { finishRound } from '../round';

export function applyCard(ctx: Ctx, p: PlayerId, card: Card): void {
  const r = roundOf(ctx);
  const hand = r.hands[p];

  // Marriage: leading a Q while holding its K declares it; trump applies to this trick already.
  if (r.trick.cards.length === 0 && card.rank === 'Q' && hasMarriage(hand, card.suit) && !r.marriages[p].includes(card.suit)) {
    r.marriages[p].push(card.suit);
    r.trump = card.suit;
    emit(ctx, { type: 'marriage', p, suit: card.suit, points: RULES.marriageValues[card.suit] });
  }

  r.hands[p] = removeCard(hand, card);
  r.trick.cards.push({ p, card: { ...card } });
  emit(ctx, { type: 'cardPlayed', p, card: { ...card } });

  if (r.trick.cards.length < r.active.length) return;

  const won = getTrickWinnerWithReason(r.trick.cards, r.trump);
  const cards = r.trick.cards.map(t => t.card);
  const points = handPoints(cards);
  r.tricksWon[won.winnerId].push(cards);
  r.lastTrick = { cards: clone(r.trick.cards), winner: won.winnerId, points };
  emit(ctx, {
    type: 'trickWon',
    p: won.winnerId,
    cards: clone(r.trick.cards),
    card: { ...won.winningCard },
    points,
    byTrump: won.byTrump,
  });
  r.trick = { leader: won.winnerId, cards: [] };

  if (r.active.every(q => r.hands[q].length === 0)) finishRound(ctx, false);
}
```

```ts
/** Every card ({suit, rank} object) found anywhere inside x, as cardKey strings. */
export function cardKeysIn(x: unknown, out: string[] = []): string[] {
  if (Array.isArray(x)) {
    for (const v of x) cardKeysIn(v, out);
  } else if (x && typeof x === 'object') {
    if (isCard(x)) out.push(cardKey(x));
    else for (const v of Object.values(x)) cardKeysIn(v, out);
  }
  return out;
}

/** Cards `me` must not be able to see in state `s`. */
export function hiddenCardKeys(s: GameState, me: PlayerId): Set<string> {
  const hidden = new Set<string>();
  const r = s.round;
  if (!r) return hidden;
  for (const p of r.active) if (p !== me) for (const card of r.hands[p]) hidden.add(cardKey(card));
  const biddingOver = s.phase !== 'bidding';
  if (!biddingOver) for (const card of r.talon) hidden.add(cardKey(card));
  if (biddingOver && (r.talonPublic || r.bid.high === me)) for (const card of r.talon) hidden.delete(cardKey(card));
  if (r.handoutGiven && r.bid.high === me) {
    for (const card of Object.values(r.handoutGiven)) hidden.delete(cardKey(card));
  }
  return hidden;
}
```

```ts
import type { Card, GameEvent, GameState, PlayerId, PlayerView, Round, RoundView } from './types';
import { legalActions, turnOf } from './actions';
import { clone } from './ctx';
import { handPoints } from './cards';
import { maxBidFor } from './bidding';
import { cardRuleMessage } from './tricks';

/** Everything `me` is allowed to know. This is the only state that may leave the server. */
export function viewFor(s: GameState, me: PlayerId): PlayerView {
  return {
    v: 1,
    seq: s.seq,
    me,
    seats: clone(s.seats),
    maxPlayers: s.maxPlayers,
    firstDealer: s.firstDealer,
    phase: s.phase,
    paused: s.paused ? { ...s.paused } : null,
    winner: s.winner,
    scores: clone(s.scores),
    rounds: clone(s.rounds),
    turn: turnOf(s),
    legal: legalActions(s, me),
    round: s.round ? roundView(s, s.round, me) : null,
  };
}

function roundView(s: GameState, r: Round, me: PlayerId): RoundView {
  const bidder = r.bid.high;
  const talonVisible = s.phase !== 'bidding' && (r.talonPublic || me === bidder);
  const myHand = r.hands[me];
  let handout: Partial<Record<PlayerId, Card>> | null = null;
  if (r.handoutGiven) {
    if (me === bidder) handout = clone(r.handoutGiven);
    else {
      const mine = r.handoutGiven[me];
      handout = mine ? { [me]: { ...mine } } : {};
    }
  }
  const per = <T>(f: (p: PlayerId) => T): Record<PlayerId, T> => Object.fromEntries(r.active.map(p => [p, f(p)]));
  return {
    number: r.number,
    dealer: r.dealer,
    active: [...r.active],
    sittingOut: s.seats.length === 4 ? r.dealer : null,
    hand: myHand ? clone(myHand) : [],
    handCounts: per(p => r.hands[p].length),
    talon: talonVisible ? clone(r.talon) : null,
    talonPublic: r.talonPublic,
    bid: clone(r.bid),
    maxBid: myHand ? maxBidFor(myHand) : 0,
    trump: r.trump,
    marriages: clone(r.marriages),
    trick: clone(r.trick),
    lastTrick: r.lastTrick ? clone(r.lastTrick) : null,
    played: r.active.flatMap(p => r.tricksWon[p].flat()).map(card => ({ ...card })),
    tricksTaken: per(p => r.tricksWon[p].length),
    trickPoints: per(p => r.tricksWon[p].reduce((sum, t) => sum + handPoints(t), 0)),
    handout,
  };
}

/** The events `p` may receive. */
export function eventsFor(events: GameEvent[], p: PlayerId): GameEvent[] {
  return events.filter(e => e.audience === 'all' || e.audience.includes(p));
}

/** Why `card` can't be played by the viewer right now, or null if it can. */
export function explainIllegal(view: PlayerView, card: Card): string | null {
  const r = view.round;
  if (view.paused) return 'The game is paused';
  if (!r || view.phase !== 'tricks') return "You can't play a card right now";
  if (view.turn !== view.me) {
    const name = view.seats.find(x => x.id === view.turn)?.name ?? 'the next player';
    return `Wait for ${name} to play`;
  }
  return cardRuleMessage(r.hand, r.trick.cards, r.trump, card);
}
```

```ts
import type { Card, PlayerId, Rank, Suit } from '../types';
import { RULES, SUITS } from '../rules';
import { hasMarriage, marriagesInHand, totalMarriageValue } from '../cards';
import { maxBidFor } from '../bidding';

// Port of the original AIPlayer evaluation heuristics (apps/server/src/ai/index.ts).

const PTS = RULES.cardPoints;
const STR = RULES.rankStrength;

export function cardValue(card: Card): number {
  return PTS[card.rank] + STR[card.rank];
}

function has(hand: Card[], suit: Suit, rank: Rank): boolean {
  return hand.some(c => c.suit === suit && c.rank === rank);
}

function suitCounts(hand: Card[]): number[] {
  return SUITS.map(suit => hand.filter(c => c.suit === suit).length);
}

export function evaluateHandStrength(hand: Card[]): number {
  let strength = 0;
  strength += hand.filter(c => c.rank === 'A').length * 0.15;
  strength += hand.filter(c => c.rank === '10').length * 0.1;
  for (const suit of SUITS) if (has(hand, suit, 'A') && has(hand, suit, '10')) strength += 0.1;
  strength += hand.filter(c => c.rank === 'K').length * 0.05;
  strength += marriagesInHand(hand).length * 0.2;
  const counts = suitCounts(hand);
  if (Math.max(...counts) >= 4) strength += 0.1;
  strength += counts.filter(n => n === 0).length * 0.08;
  return Math.min(1, strength);
}

/** Expected round points for a 7-card hand before seeing the talon. */
export function expectedBidPoints(hand: Card[]): number {
  let points = totalMarriageValue(hand);
  for (const card of hand) {
    if (card.rank === 'A') points += 11;
    else if (card.rank === '10') points += has(hand, card.suit, 'A') ? 9 : 4;
    else if (card.rank === 'K') points += 2;
  }
  // Talon estimate: ~10 base, plus ~12% chance of completing each half-marriage.
  const nearMarriages = SUITS.filter(
    suit => !hasMarriage(hand, suit) && (has(hand, suit, 'Q') || has(hand, suit, 'K')),
  );
  let talonEstimate = 10;
  for (const suit of nearMarriages) talonEstimate += RULES.marriageValues[suit] * 0.12;
  return points + talonEstimate;
}

export type BidDecision = { shouldBid: true; amount: number } | { shouldBid: false };

export function decideBid(hand: Card[], currentBid: number, passedCount: number): BidDecision {
  const maxBid = maxBidFor(hand);
  const minBid = currentBid + RULES.bidStep;
  if (minBid > maxBid) return { shouldBid: false };
  const expected = expectedBidPoints(hand);
  const aggression = passedCount > 0 ? 1.15 : 1.0;
  const targetBid = Math.min(Math.floor((expected * aggression) / 10) * 10, maxBid);
  if (targetBid >= minBid) return { shouldBid: true, amount: minBid };
  if (evaluateHandStrength(hand) > 0.7 && minBid <= RULES.maxBidBase) return { shouldBid: true, amount: minBid };
  return { shouldBid: false };
}

/** Expected round points for the 10-card hand (7 + talon) before the hand-out. */
export function postTalonExpectedPoints(hand: Card[]): number {
  let points = totalMarriageValue(hand);
  for (const card of hand) {
    if (card.rank === 'A') points += 11;
    else if (card.rank === '10') points += has(hand, card.suit, 'A') ? 10 : 4;
    else if (card.rank === 'K') points += 2;
    else if (card.rank === 'Q') points += 1;
  }
  for (const suit of marriagesInHand(hand)) {
    const n = hand.filter(c => c.suit === suit).length;
    if (n >= 4) points += 10;
    else if (n >= 3) points += 5;
  }
  points += suitCounts(hand).filter(n => n === 0).length * 8;
  for (const suit of SUITS) if (has(hand, suit, 'A') && has(hand, suit, '10')) points += 5;
  return points;
}

export function decidePlayOrThrow(hand: Card[], bid: number, onBarrel: boolean): 'play' | 'throw' {
  const expected = postTalonExpectedPoints(hand);
  // Throwing at 100 is free; playing and failing costs 100.
  if (bid <= RULES.autoBid) return expected >= 80 ? 'play' : 'throw';
  // On the barrel a throw costs the bid anyway — always play.
  if (onBarrel) return 'play';
  const threshold = bid <= 130 ? 0.8 : bid <= 170 ? 0.85 : 0.9;
  return expected >= bid * threshold ? 'play' : 'throw';
}

/** Higher = more willing to give this card away in the hand-out. */
export function handoutGiveScore(card: Card, hand: Card[]): number {
  if (hasMarriage(hand, card.suit) && (card.rank === 'Q' || card.rank === 'K')) return -100;
  let score = 0;
  const suitLength = hand.filter(c => c.suit === card.suit).length;
  if (suitLength === 1) score += 20; // creates a void
  else if (suitLength === 2) score += 12; // creates a singleton
  else score -= suitLength * 2;
  score -= cardValue(card) * 2;
  if (card.rank === 'A') score -= 15;
  if (card.rank === '10') score += has(hand, card.suit, 'A') ? -10 : 2;
  if (card.rank === 'Q' || card.rank === 'K') score -= 3;
  if (card.rank === '9') score += 8;
  return score;
}

/** Picks the two most expendable cards; the better one goes to the opponent with the lower score. */
export function decideHandout(
  hand: Card[],
  recipients: PlayerId[],
  totals: Record<PlayerId, number>,
): Record<PlayerId, Card> {
  const scored = hand
    .map(card => ({ card, score: handoutGiveScore(card, hand) }))
    .sort((a, b) => b.score - a.score);
  const card1 = scored[0].card;
  const card2 = scored[1].card;
  const [x, y] = recipients;
  const [better, worse] = cardValue(card1) >= cardValue(card2) ? [card1, card2] : [card2, card1];
  const [weaker, stronger] = (totals[x] ?? 0) <= (totals[y] ?? 0) ? [x, y] : [y, x];
  return { [weaker]: { ...better }, [stronger]: { ...worse } };
}
```

```ts
import type { Card, PlayerId, Suit, TrickCard } from '../types';
import { RANKS, RULES, SUITS } from '../rules';
import { cardEquals, hasMarriage } from '../cards';
import { cardValue } from './eval';

const PTS = RULES.cardPoints;
const STR = RULES.rankStrength;

export function lowestValue(cards: Card[]): Card {
  return [...cards].sort((a, b) => cardValue(a) - cardValue(b))[0];
}

export function highestValue(cards: Card[]): Card {
  return [...cards].sort((a, b) => cardValue(b) - cardValue(a))[0];
}

export function highestPoints(cards: Card[]): Card {
  return [...cards].sort((a, b) => PTS[b.rank] - PTS[a.rank])[0];
}

function groupBySuit(cards: Card[]): Map<Suit, Card[]> {
  const groups = new Map<Suit, Card[]>();
  for (const card of cards) {
    const group = groups.get(card.suit) ?? [];
    group.push(card);
    groups.set(card.suit, group);
  }
  return groups;
}

/** The original AI's beat test: unlike the rules' canBeat, a lead-suit card beats an off-suit non-trump. */
function aiCanBeat(card: Card, toBeat: Card, leadSuit: Suit, trump: Suit | null): boolean {
  if (trump) {
    if (card.suit === trump && toBeat.suit !== trump) return true;
    if (card.suit !== trump && toBeat.suit === trump) return false;
    if (card.suit === trump && toBeat.suit === trump) return STR[card.rank] > STR[toBeat.rank];
  }
  if (card.suit === toBeat.suit) return STR[card.rank] > STR[toBeat.rank];
  if (card.suit === leadSuit && toBeat.suit !== leadSuit) return true;
  return false;
}

function currentWinner(cards: Card[], leadSuit: Suit, trump: Suit | null): Card {
  let winner = cards[0];
  for (let i = 1; i < cards.length; i++) if (aiCanBeat(cards[i], winner, leadSuit, trump)) winner = cards[i];
  return winner;
}

/** Cards neither in our hand nor played yet — still held by opponents (or unseen). */
export function remainingCards(hand: Card[], played: Card[]): Card[] {
  const out: Card[] = [];
  for (const suit of SUITS) {
    for (const rank of RANKS) {
      const card = { suit, rank };
      if (!played.some(p => cardEquals(p, card)) && !hand.some(h => cardEquals(h, card))) out.push(card);
    }
  }
  return out;
}

function pickSuitWithMostPoints(aces: Card[], remaining: Card[]): Card {
  if (aces.length === 1) return aces[0];
  let best = aces[0];
  let bestPoints = 0;
  for (const ace of aces) {
    const suitPoints = remaining.filter(c => c.suit === ace.suit).reduce((sum, c) => sum + PTS[c.rank], 0);
    if (suitPoints > bestPoints) {
      bestPoints = suitPoints;
      best = ace;
    }
  }
  return best;
}

/** Least valuable card to throw away; keeps aces, protected 10s, trumps and marriage pairs. */
export function lowestExpendable(cards: Card[], trump: Suit | null): Card {
  const scored = cards.map(card => {
    let keep = cardValue(card);
    if (card.rank === 'A') keep += 30;
    if (card.rank === '10') keep += cards.some(c => c.suit === card.suit && c.rank === 'A') ? 20 : 5;
    if (trump && card.suit === trump) keep += 10;
    if (
      (card.rank === 'Q' || card.rank === 'K') &&
      cards.some(c => c.suit === card.suit && c.rank === (card.rank === 'Q' ? 'K' : 'Q'))
    ) {
      keep += 15;
    }
    return { card, keep };
  });
  scored.sort((a, b) => a.keep - b.keep);
  return scored[0].card;
}

/** Highest-value marriage in hand that has not been declared yet. */
export function marriageToDeclare(hand: Card[], declared: Suit[]): Suit | null {
  return RULES.marriageOrder.find(suit => hasMarriage(hand, suit) && !declared.includes(suit)) ?? null;
}

export interface CardContext {
  valid: Card[];
  trick: TrickCard[];
  trump: Suit | null;
  isBidder: boolean;
  bidder: PlayerId;
  hand: Card[];
  /** Cards from completed tricks this round. */
  played: Card[];
}

export function decideCard(ctx: CardContext): Card {
  if (ctx.valid.length === 1) return ctx.valid[0];
  const remaining = remainingCards(ctx.hand, [...ctx.played, ...ctx.trick.map(t => t.card)]);
  if (ctx.trick.length === 0) return decideLeadCard(ctx.valid, ctx.trump, ctx.isBidder, remaining);
  return decideFollowCard(ctx.valid, ctx.trick, ctx.trump, ctx.isBidder, ctx.bidder, remaining);
}

function decideLeadCard(valid: Card[], trump: Suit | null, isBidder: boolean, remaining: Card[]): Card {
  if (isBidder) {
    // Lead aces first (non-trump: suit with most outstanding points).
    const aces = valid.filter(c => c.rank === 'A');
    if (aces.length > 0) {
      const nonTrumpAces = aces.filter(c => c.suit !== trump);
      if (nonTrumpAces.length > 0) return pickSuitWithMostPoints(nonTrumpAces, remaining);
      return aces[0];
    }
    // 10s whose ace is gone.
    for (const ten of valid.filter(c => c.rank === '10')) {
      if (!remaining.some(r => r.suit === ten.suit && r.rank === 'A')) return ten;
    }
    // Pull trumps with a strong trump holding.
    if (trump) {
      const myTrumps = valid.filter(c => c.suit === trump);
      if (myTrumps.length >= 2 && remaining.some(c => c.suit === trump)) return highestValue(myTrumps);
    }
    // Probe low from the longest non-trump suit.
    const nonTrump = valid.filter(c => c.suit !== trump);
    if (nonTrump.length > 0) {
      let longest: Card[] | null = null;
      for (const cards of groupBySuit(nonTrump).values()) {
        if (!longest || cards.length > longest.length) longest = cards;
      }
      if (longest) return lowestValue(longest);
    }
    return lowestValue(valid);
  }

  // Defender leading: grab points.
  const nonTrumpAces = valid.filter(c => c.rank === 'A' && c.suit !== trump);
  if (nonTrumpAces.length > 0) return pickSuitWithMostPoints(nonTrumpAces, remaining);
  const safeTens = valid.filter(
    c => c.rank === '10' && c.suit !== trump && !remaining.some(r => r.suit === c.suit && r.rank === 'A'),
  );
  if (safeTens.length > 0) return safeTens[0];
  if (trump) {
    const myTrumps = valid.filter(c => c.suit === trump);
    if (myTrumps.length >= 2 && remaining.some(c => c.suit === trump)) return lowestValue(myTrumps);
  }
  const nonTrumpCards = valid.filter(c => c.suit !== trump);
  if (nonTrumpCards.length > 0) {
    let bestSuit: Card[] | null = null;
    let bestScore = -1;
    for (const [suit, cards] of groupBySuit(nonTrumpCards)) {
      const opponentCards = remaining.filter(c => c.suit === suit).length;
      if (opponentCards === 0) continue; // they'd trump us
      const score = cards.length * 2 + opponentCards;
      if (score > bestScore) {
        bestScore = score;
        bestSuit = cards;
      }
    }
    if (bestSuit) return lowestValue(bestSuit);
    return lowestValue(nonTrumpCards);
  }
  return lowestValue(valid);
}

function decideFollowCard(
  valid: Card[],
  trick: TrickCard[],
  trump: Suit | null,
  isBidder: boolean,
  bidder: PlayerId,
  remaining: Card[],
): Card {
  const leadSuit = trick[0].card.suit;
  const played = trick.map(t => t.card);
  const winningCard = currentWinner(played, leadSuit, trump);
  const winningPlayer = trick[played.indexOf(winningCard)].p;
  const followingSuit = valid.some(c => c.suit === leadSuit);
  const beating = valid.filter(c => aiCanBeat(c, winningCard, leadSuit, trump));

  if (!followingSuit) {
    return decideOffSuitCard(valid, trick, trump, isBidder, bidder, winningCard, winningPlayer, remaining);
  }
  if (isBidder) return beating.length > 0 ? lowestValue(beating) : lowestValue(valid);

  if (trick.length === 1) {
    if (trick[0].p === bidder) return beating.length > 0 ? lowestValue(beating) : lowestValue(valid);
    const partnerCard = played[0];
    if (STR[partnerCard.rank] >= 4) {
      // Partner led a 10 or A: feed points without overtaking.
      const feed = valid.filter(c => !aiCanBeat(c, partnerCard, leadSuit, trump));
      return feed.length > 0 ? highestPoints(feed) : lowestValue(valid);
    }
    return beating.length > 0 ? lowestValue(beating) : lowestValue(valid);
  }

  if (winningPlayer !== bidder) {
    const feed = valid.filter(c => !aiCanBeat(c, winningCard, leadSuit, trump));
    return feed.length > 0 ? highestPoints(feed) : lowestValue(valid);
  }
  return beating.length > 0 ? lowestValue(beating) : lowestValue(valid);
}

function decideOffSuitCard(
  valid: Card[],
  trick: TrickCard[],
  trump: Suit | null,
  isBidder: boolean,
  bidder: PlayerId,
  winningCard: Card,
  winningPlayer: PlayerId,
  remaining: Card[],
): Card {
  const leadSuit = trick[0].card.suit;
  const myTrumps = trump ? valid.filter(c => c.suit === trump) : [];
  const trickPointValue = trick.reduce((sum, t) => sum + PTS[t.card.rank], 0);
  const beatingTrumps = myTrumps.filter(c => aiCanBeat(c, winningCard, leadSuit, trump));

  if (isBidder) return beatingTrumps.length > 0 ? lowestValue(beatingTrumps) : lowestExpendable(valid, trump);
  if (winningPlayer !== bidder) return lowestExpendable(valid, trump); // partner winning: dump
  if (beatingTrumps.length > 0) {
    if (trickPointValue >= 10 || myTrumps.length >= 2) return lowestValue(beatingTrumps);
    if (remaining.length <= 12) return lowestValue(beatingTrumps); // late game: fight for every trick
  }
  return lowestExpendable(valid, trump);
}
```

```ts
  if (options.length === 0) throw new Error(`botAction: ${view.me} has nothing to do`);
  const chosen = decide(view, options);
  if (chosen && options.some(a => actionsEqual(a, chosen))) return chosen;
  return options[Math.floor(rng() * options.length)];
}

function decide(view: PlayerView, options: Action[]): Action | null {
  const r = view.round;
  if (!r) return null;
  const hand = r.hand;
  switch (view.phase) {
    case 'bidding': {
      const d = decideBid(hand, r.bid.amount, r.bid.passed.length);
      return d.shouldBid ? { type: 'bid', amount: d.amount } : { type: 'pass' };
    }
    case 'decision': {
      const onBarrel = isOnBarrel(view.scores[view.me]?.total ?? 0);
      return decidePlayOrThrow(hand, r.bid.amount, onBarrel) === 'play' ? { type: 'play' } : { type: 'throw' };
    }
    case 'handout': {
      const recipients = r.active.filter(p => p !== view.me);
      const totals = Object.fromEntries(recipients.map(p => [p, view.scores[p]?.total ?? 0]));
      return { type: 'handout', to: decideHandout(hand, recipients, totals) };
    }
    case 'tricks': {
      if (r.trick.cards.length === 0) {
        const suit = marriageToDeclare(hand, r.marriages[view.me] ?? []);
        if (suit) return { type: 'card', card: { suit, rank: 'Q' } };
      }
      const valid = options.flatMap(a => (a.type === 'card' ? [a.card] : []));
      return {
        type: 'card',
        card: decideCard({
          valid,
          trick: r.trick.cards,
          trump: r.trump,
          isBidder: view.me === r.bid.high,
          bidder: r.bid.high,
          hand,
          played: r.played,
        }),
      };
    }
    default:
      return null;
  }
}
```

```ts
import { describe, it, expect } from 'vitest';
import type { Action, Card, GameState, PlayerId, RoundSummary, Seat } from '../src/types';
import { createGame } from '../src/game';
import { reduce } from '../src/reduce';
import { actionsEqual, legalActions, turnOf } from '../src/actions';
import { viewFor } from '../src/view';
import { botAction } from '../src/bot';
import { makeRandom } from '../src/rng';
import { cardKey } from '../src/cards';
import { SEATS3, SEATS4, cardKeysIn, hiddenCardKeys } from './helpers';

const GAMES_3P = 1200;
const GAMES_4P = 800;
const FULL_VIEW_CHECK_GAMES = 100; // per mode: check every seat's view at every step
const MAX_STEPS = 20_000;

function assert(cond: unknown, msg: string): asserts cond {
  if (!cond) throw new Error(msg);
}

// Independent re-statement of spec §3.9 rounding.
const r10 = (n: number) => (n % 10 >= 6 ? n - (n % 10) + 10 : n - (n % 10));
const barrel = (t: number) => t >= 800 && t < 1000;

function roundCards(s: GameState): Card[] {
  const r = s.round!;
  const cards = [
    ...Object.values(r.hands).flat(),
    ...r.trick.cards.map(t => t.card),
    ...Object.values(r.tricksWon).flat(2),
  ];
  if (s.phase === 'bidding') cards.push(...r.talon);
  return cards;
}

function checkNoLeak(s: GameState, me: PlayerId, tag: string): void {
  const hidden = hiddenCardKeys(s, me);
  for (const k of cardKeysIn(viewFor(s, me))) assert(!hidden.has(k), `${tag}: view for ${me} leaks ${k}`);
}

function checkSummary(sum: RoundSummary, prev: Record<PlayerId, number>, tag: string): void {
  for (const pr of sum.players) {
    const before = prev[pr.playerId];
    assert(pr.newTotalScore === before + pr.scoreChange, `${tag}: total mismatch for ${pr.playerId}`);
    const onBarrel = barrel(before);
    if (sum.outcome === 'thrown') {
      let expected = 0;
      if (sum.bid > 100) {
        if (pr.playerId === sum.bidder) expected = -sum.bid;
        else if (!pr.sittingOut && !onBarrel) expected = 60;
      }
      assert(pr.scoreChange === expected, `${tag}: throw change ${pr.scoreChange} != ${expected} for ${pr.playerId}`);
      continue;
    }
    if (pr.playerId === sum.bidder) {
      const made = pr.totalRoundPoints >= sum.bid;
      assert(sum.outcome === (made ? 'made' : 'failed'), `${tag}: outcome mismatch`);
      assert(pr.scoreChange === (made ? r10(pr.totalRoundPoints) : -sum.bid), `${tag}: bidder change wrong`);
    } else if (onBarrel) {
      assert(pr.scoreChange === 0, `${tag}: barrel player ${pr.playerId} scored`);
    } else {
      assert(pr.scoreChange === r10(pr.totalRoundPoints), `${tag}: defender change wrong`);
    }
  }
  if (sum.outcome !== 'thrown') {
    const trickTotal = sum.players.filter(p => !p.sittingOut).reduce((t, p) => t + p.trickPoints, 0);
    assert(trickTotal === 120, `${tag}: trick points ${trickTotal} != 120`);
  }
}

interface Played {
  state: GameState;
  log: Array<{ p: PlayerId; action: Action }>;
}

function playGame(seed: string, seats: Seat[], firstDealer: number, fullViews: boolean, jsonRoundTrip = false): Played {
  const rand = makeRandom(`bots:${seed}`);
  let s = createGame({ seed, seats, maxPlayers: seats.length as 3 | 4, firstDealer });
  const log: Played['log'] = [];
  let steps = 0;
  while (s.phase !== 'gameEnd') {
    const tag = `${seed}#${steps}`;
    assert(++steps < MAX_STEPS, `${seed}: did not terminate`);
    const p = turnOf(s);
    assert(p, `${tag}: nobody to act`);
    if (fullViews) for (const seat of seats) checkNoLeak(s, seat.id, tag);
    else checkNoLeak(s, p, tag);
    const action = botAction(viewFor(s, p), rand);
    assert(legalActions(s, p).some(a => actionsEqual(a, action)), `${tag}: bot chose illegal ${JSON.stringify(action)}`);
    const prevTotals = Object.fromEntries(Object.entries(s.scores).map(([id, x]) => [id, x.total]));
    const res = reduce(s, p, action, steps);
    assert(res.ok, `${tag}: reduce rejected ${JSON.stringify(action)}: ${!res.ok && res.error.message}`);
    for (const e of res.events) {
      if (e.type === 'roundScored' || e.type === 'threw') checkSummary(e.summary, prevTotals, tag);
    }
    assert(res.state.seq === s.seq + 1, `${tag}: seq did not advance`);
    log.push({ p, action });
    s = jsonRoundTrip ? (JSON.parse(JSON.stringify(res.state)) as GameState) : res.state;
    if (s.phase !== 'gameEnd') {
      const keys = roundCards(s).map(cardKey);
      assert(keys.length === 24 && new Set(keys).size === 24, `${tag}: card conservation broken (${keys.length})`);
    }
    const shadow = Object.values(s.scores).every(x => x.total === x.history.reduce((a, b) => a + b, 0));
    assert(shadow, `${tag}: totals differ from history`);
  }
  assert(s.winner, `${seed}: no winner`);
  assert(s.scores[s.winner].total >= 1000, `${seed}: winner below 1000`);
  return { state: s, log };
}

describe('simulation', () => {
  it(`plays ${GAMES_3P} three-player bot games`, () => {
    for (let i = 0; i < GAMES_3P; i++) playGame(`3p-${i}`, SEATS3, i % 3, i < FULL_VIEW_CHECK_GAMES);
  }, 600_000);

  it(`plays ${GAMES_4P} four-player bot games`, () => {
    for (let i = 0; i < GAMES_4P; i++) playGame(`4p-${i}`, SEATS4, i % 4, i < FULL_VIEW_CHECK_GAMES);
  }, 600_000);

  it('is deterministic and survives JSON round-trips', () => {
    for (const [seed, seats] of [['det-3', SEATS3], ['det-4', SEATS4]] as const) {
      const a = playGame(seed, seats, 1, false);
      const b = playGame(seed, seats, 1, false, true);
      expect(b.state).toEqual(a.state);
      expect(b.log).toEqual(a.log);
      // replaying the logged actions from scratch reproduces the final state
      let s = createGame({ seed, seats, maxPlayers: seats.length as 3 | 4, firstDealer: 1 });
      a.log.forEach(({ p, action }, i) => {
        const res = reduce(s, p, action, i + 1);
        if (!res.ok) throw new Error(res.error.message);
        s = res.state;
      });
      expect(s).toEqual(a.state);
    }
  }, 120_000);
});
```

```ts
import type { Action, Advice, Card, PlayerId, PlayerView, Suit } from '../types';
import { RANKS, RULES, SUITS, SUIT_SYMBOL } from '../rules';
import { cardEquals, cardLabel, handPoints, hasMarriage, marriagesInHand } from '../cards';
import { maxBidFor } from '../bidding';
import { canBeat, getHighestCardInTrick } from '../tricks';
import { roundToTen } from '../scoring';
import { botAction } from '../bot';
import { expectedBidPoints, postTalonExpectedPoints } from '../bot/eval';
import { nameOf } from './names';

const MV = RULES.marriageValues;
const STR = RULES.rankStrength;
const sym = (suit: Suit): string => SUIT_SYMBOL[suit];

/** The coach's recommendation for the viewer's current decision, or null when there is none. */
export function advise(view: PlayerView): Advice | null {
  const r = view.round;
  if (!r || view.paused || view.turn !== view.me) return null;
  if (!view.legal.some(a => a.type !== 'pause' && a.type !== 'resume')) return null;
  const action = botAction(view, () => 0);
  switch (action.type) {
    case 'bid':
    case 'pass':
      return adviseBid(view, action);
    case 'play':
    case 'throw':
      return adviseDecision(view, action);
    case 'handout':
      return adviseHandout(view, action, action.to);
    case 'card':
      return adviseCard(view, action, action.card);
    default:
      return null;
  }
}

function adviseBid(view: PlayerView, action: Action): Advice {
  const r = view.round!;
  const hand = r.hand;
  const next = r.bid.amount + RULES.bidStep;
  const max = maxBidFor(hand);
  const worth = roundToTen(Math.round(expectedBidPoints(hand)));
  const headline =
    action.type === 'bid'
      ? `Bid ${next} — this hand looks worth about ${worth}`
      : next > max
        ? `Pass — you can't bid above ${max}`
        : `Pass — ${next} is more than this hand is likely to make`;
  const reasons = [`Your max bid is ${max} (120 + marriages in hand)`];
  for (const suit of marriagesInHand(hand)) {
    reasons.push(`K+Q ${sym(suit)} marriage: +${MV[suit]} when you lead the Q and win a trick`);
  }
  const aces = hand.filter(c => c.rank === 'A').length;
  if (aces > 0) reasons.push(`${aces} ace${aces > 1 ? 's' : ''} — 11 points each and usually a trick`);
  reasons.push('The talon adds 3 unseen cards — count on roughly 10 points from it');
  if (action.type === 'bid' && r.bid.passed.length > 0) reasons.push('Someone already passed, so a little extra risk is fine');
  return { action, headline, reasons };
}

function adviseDecision(view: PlayerView, action: Action): Advice {
  const r = view.round!;
  const hand = r.hand;
  const bid = r.bid.amount;
  const est = roundToTen(Math.round(postTalonExpectedPoints(hand)));
  const free = bid <= RULES.autoBid;
  const headline =
    action.type === 'play'
      ? `Play — you can expect about ${est} toward your ${bid}`
      : free
        ? "Throw in — it's free at 100 and this hand looks weak"
        : `Throw in — ${bid} looks out of reach (about ${est})`;
  const share = Math.floor(RULES.throwPool / 2);
  const reasons = [
    free
      ? 'Throwing at 100 costs nothing: the cards are simply dealt again'
      : `Throwing costs you ${bid} and gives each opponent ${share} (0 if on the barrel)`,
    `Playing and falling short costs ${bid}`,
  ];
  for (const suit of marriagesInHand(hand)) reasons.push(`Your K+Q ${sym(suit)} marriage is worth ${MV[suit]}`);
  const voids = SUITS.filter(s => !hand.some(c => c.suit === s));
  if (voids.length > 0) reasons.push(`You're void in ${voids.map(sym).join(' ')} — you can trump those leads`);
  return { action, headline, reasons };
}

function adviseHandout(view: PlayerView, action: Action, to: Record<PlayerId, Card>): Advice {
  const r = view.round!;
  const entries = Object.entries(to);
  const headline = `Give ${entries.map(([p, card]) => `${cardLabel(card)} to ${nameOf(view, p)}`).join(' and ')}`;
  const given = entries.map(([, card]) => card);
  const after = r.hand.filter(h => !given.some(g => cardEquals(g, h)));
  const reasons: string[] = [];
  for (const card of given) {
    if (!after.some(h => h.suit === card.suit)) {
      reasons.push(`Giving ${cardLabel(card)} leaves you void in ${sym(card.suit)} — you can trump that suit later`);
    } else if (handPoints([card]) === 0) {
      reasons.push(`${cardLabel(card)} is worth 0 points`);
    } else {
      reasons.push(`${cardLabel(card)} is one of your least useful cards`);
    }
  }
  if (marriagesInHand(after).length > 0) reasons.push('Keep your K+Q pairs — each one is a marriage');
  if (after.some(h => h.rank === 'A')) reasons.push('Keep your aces — they win tricks');
  if (entries.length === 2) {
    const [p1, p2] = entries.map(([p]) => p);
    const t1 = view.scores[p1]?.total ?? 0;
    const t2 = view.scores[p2]?.total ?? 0;
    if (t1 !== t2) reasons.push(`The better card goes to ${nameOf(view, t1 < t2 ? p1 : p2)}, who has the lower score`);
  }
  return { action, headline, reasons: [...new Set(reasons)] };
}

function adviseCard(view: PlayerView, action: Action, card: Card): Advice {
  const r = view.round!;
  const label = cardLabel(card);
  const legalCards = view.legal.flatMap(a => (a.type === 'card' ? [a.card] : []));
  const reasons: string[] = [];
  if (legalCards.length === 1) reasons.push("It's your only legal card");

  if (r.trick.cards.length === 0) {
    const declared = r.marriages[view.me] ?? [];
    if (card.rank === 'Q' && hasMarriage(r.hand, card.suit) && !declared.includes(card.suit)) {
      return {
        action,
        headline: `Lead ${label} to declare your ${sym(card.suit)} marriage`,
        reasons: [
          `Leading a Q with its K in hand declares the marriage: +${MV[card.suit]}`,
          `${sym(card.suit)} become trumps straight away — even for this trick`,
          'Marriage points only count if you win at least one trick',
        ],
      };
    }
    const known = [...r.played, ...r.hand];
    const higherOut = RANKS.some(
      rank => STR[rank] > STR[card.rank] && !known.some(k => k.suit === card.suit && k.rank === rank),
    );
    if (!higherOut) reasons.push(`${label} is the highest ${sym(card.suit)} left — a likely winner`);
    else if (r.trump === card.suit) reasons.push("Leading trumps pulls trumps out of your opponents' hands");
    else reasons.push('A low lead feels out the suit without risking points');
    return { action, headline: `Lead ${label}`, reasons };
  }

  const lead = r.trick.cards[0].card;
  const onTable = r.trick.cards.map(t => t.card);
  const winning = getHighestCardInTrick(onTable, lead.suit, r.trump);
  const winner = r.trick.cards.find(t => cardEquals(t.card, winning))!.p;
  const wins = cardEquals(getHighestCardInTrick([...onTable, card], lead.suit, r.trump), card);
  const holdsLead = r.hand.some(h => h.suit === lead.suit);
  if (!holdsLead) {
    reasons.push(`You have no ${sym(lead.suit)}, so any card is allowed`);
  } else if (r.trick.cards.length === 1 && r.hand.some(h => h.suit === lead.suit && canBeat(h, lead, lead.suit, r.trump))) {
    reasons.push(`As first to respond you must beat ${cardLabel(lead)} if you can`);
  }
  if (wins) {
    const last = r.trick.cards.length === r.active.length - 1;
    reasons.push(
      last
        ? `${label} takes the trick (${handPoints([...onTable, card])} points)`
        : `${label} beats everything played so far`,
    );
    if (r.trump && card.suit === r.trump && lead.suit !== r.trump) {
      reasons.push(`Trumps (${sym(r.trump)}) beat every other suit`);
    }
  } else if (view.me !== r.bid.high && winner !== r.bid.high) {
    const pts = handPoints([card]);
    reasons.push(
      pts > 0
        ? `${nameOf(view, winner)} is winning — ${label} feeds them ${pts} points`
        : `${nameOf(view, winner)} is winning — no need to fight for it`,
    );
  } else {
    reasons.push("You can't win this one, so play your least useful card");
  }
  return { action, headline: `Play ${label}`, reasons };
}
```

```ts
import type { GameEvent, PlayerView, RoundSummary } from '../types';
import { RULES, SUIT_SYMBOL } from '../rules';
import { cardLabel } from '../cards';
import { nameOf } from './names';

/** One short sentence explaining an event to `view.me`, or null if it needs no explanation. */
export function explainEvent(event: GameEvent, view: PlayerView): string | null {
  switch (event.type) {
    case 'marriage': {
      const s = SUIT_SYMBOL[event.suit];
      return `${nameOf(view, event.p)} declared the ${s} marriage: +${event.points}. ${s} are trumps now.`;
    }
    case 'trickWon':
      return event.byTrump
        ? `${nameOf(view, event.p)} won with ${cardLabel(event.card)} — trumps beat every other suit.`
        : null;
    case 'biddingWon': {
      const who = nameOf(view, event.p);
      if (event.talonPublic) return `${who} won the bid at ${event.amount}. Over 100, so everyone sees the talon.`;
      const sees = event.p === view.me ? 'you see' : `${who} sees`;
      return `${who} won the bid at ${event.amount}. At 100 only ${sees} the talon.`;
    }
    case 'threw': {
      const who = nameOf(view, event.p);
      if (event.amount <= RULES.autoBid) return `${who} threw in at 100 — nobody scores, new deal.`;
      const share = Math.floor(RULES.throwPool / 2);
      return `${who} threw in at ${event.amount}: −${event.amount}, everyone else +${share} (0 on the barrel).`;
    }
    case 'wykladana': {
      const verb = event.p === view.me ? 'have' : 'has';
      return `${nameOf(view, event.p)} ${verb} every trick guaranteed — round won outright (wykładana)!`;
    }
    case 'roundScored':
      return explainRound(event.summary, view);
    case 'gameWon':
      return `${nameOf(view, event.p)} won the game with ${event.totals[event.p]}!`;
    default:
      return null;
  }
}

function explainRound(summary: RoundSummary, view: PlayerView): string {
  const bidder = summary.players.find(p => p.playerId === summary.bidder)!;
  const name = nameOf(view, summary.bidder);
  const parts: string[] = [];
  if (summary.outcome === 'made') {
    const rounded = bidder.scoreChange !== bidder.totalRoundPoints ? ' (rounded)' : '';
    parts.push(`${name} bid ${summary.bid} and scored ${bidder.totalRoundPoints} → +${bidder.scoreChange}${rounded}`);
  } else {
    parts.push(`${name} bid ${summary.bid} but scored only ${bidder.totalRoundPoints} → −${summary.bid}`);
  }
  if (bidder.fellOffBarrel) parts.push(`${name} fell off the barrel`);
  const mine = summary.players.find(p => p.playerId === view.me);
  if (mine && mine.playerId !== summary.bidder) {
    if (mine.wasOnBarrel) parts.push("You're on the barrel — only winning a bid scores there");
    else if (mine.sittingOut) parts.push(`You sat out: +${mine.scoreChange} from the talon`);
    else parts.push(`You: +${mine.scoreChange}`);
  }
  return `${parts.join('. ')}.`;
}
```

## Self-review notes (resolved spec ambiguities)

1. **Phases**: `Phase = 'bidding' | 'decision' | 'handout' | 'tricks' | 'gameEnd'`. The spec's `'lobby'` is room-level (createGame deals round 1 immediately) and `'roundEnd'` is dropped because there are no confirmation phases: the reduce call that scores a round also deals the next one (events `roundScored` then `dealt`; the room paces the UI).
2. **Talon timing**: the talon joins the bidder's hand when bidding ends (as in the original), so the play/throw decision is made with 10 cards.
3. **Throw-ins** always produce a `RoundSummary` (`outcome: 'thrown'`) and push a history entry for every seat (0 at 100). The 4-player sitting-out dealer scores 0 on any throw-in (no talon bonus).
4. **Wykładana**: bidder credited 120 trick points and 8 tricks plus every marriage in the 8-card hand; trump = first marriage in ♥♦♣♠ order; defenders score 0; the sitting-out dealer still gets the talon bonus.
5. **Pause/resume**: any seated player may pause (any phase except gameEnd) or resume; `legalActions` lists `pause` for every seated player; bots never pause.
6. **Return types**: `explainIllegal` returns `string | null` (null = legal) and `advise` returns `Advice | null` (null when it's not the viewer's turn), slightly widening the spec's signatures.
7. **Event privacy** is an `audience` field on every event plus `eventsFor(events, playerId)`; per-recipient copies are emitted for `dealt` and `handedOut`.
8. **Ported tests**: the two barrel-attempt-counter tests are rewritten (spec §3.10: no attempt limit); `applyScores`/`createRoundResult` tests target the pure `applyScoreResult`/`summarizeRound`.
9. **Bots** stay deterministic like the original AI; `rng` is used only as a fallback when a heuristic choice is not legal.
10. **Coach in M1**: the spec's build order lists the coach under milestone 4, but this milestone includes `advise`/`explainEvent` as requested; the tutorial UI stays in milestone 4.
11. **Protocol**: no `packages/protocol` in this milestone — every type later milestones need is exported from `@tysiac/engine`.
