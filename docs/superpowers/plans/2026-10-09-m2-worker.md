# M2 Worker / Rooms / Protocol Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@tysiac/protocol` and `@tysiac/worker` (one Cloudflare Worker with a Room Durable Object per game, D1 history and a debug endpoint), tested in the Workers runtime and deployed to `https://tysiac.<subdomain>.workers.dev`.

**Architecture:** The Worker's `fetch` handles `/api/*` and `/ws/*` itself. Every other path is served from static assets (`../app/dist`). Each room code maps to one SQLite-backed `Room` Durable Object via `idFromName(code)`. The Room accepts sockets with the WebSocket Hibernation API and keeps `{playerId}` in each socket attachment. It stores room meta, the engine `GameState`, game options (seed) and a capped action log in SQLite, and runs bot moves and the 7-day cleanup off a single alarm. Room logic that needs no I/O lives in small pure modules (`lobby.ts`, `scheduler.ts`, `ratelimit.ts`, `bots.ts`, `codes.ts`). `Room.ts` only handles I/O: sockets, storage, the alarm and D1.

**Tech Stack:** TypeScript 5 (strict), pnpm 9 workspace, Node 24, wrangler 4.149, Durable Objects (SQLite, hibernation), D1, zod 4.6, vitest 4.1 + `@cloudflare/vitest-plugin` 1.4.

**Spec:** `docs/superpowers/specs/2026-10-09-tysiac-rebuild-design.md` (§2 architecture and free-plan constraints, §5 protocol, §6 Room DO, §8 history, §10 worker tests, §11 rollout). **Binding contract:** `docs/superpowers/specs/2026-10-09-protocol-contract.md`. **Engine API consumed:** `docs/superpowers/plans/2026-10-09-m1-engine.md` (Task 1 `src/types.ts`; Interfaces of Tasks 5, 6, 7, 9, 11).

## Review Focus

1. **Same identity on two tabs/devices at once** (second `hello` with the same playerId+secret while the first socket is open). Expected: the old socket closes with 4000 "replaced", the player stays `connected`, and is **not** marked away. Test: Task 9 "a second socket for the same player replaces the first".
2. **Reconnect while a bot plays for you** (botFor active, your turn pending in the alarm). Expected: control returns immediately, and the pending bot move is dropped and never plays for you. Test: Task 10 "reclaiming stops the bot from playing for you".
3. **DO evicted or redeployed mid-game while sockets are hibernated.** Expected: the next message on an old socket is still attributed to the right player, and rejoining sockets get the identical state. Test: Task 11 "hibernated sockets keep their identity" and "state survives eviction".
4. **Double tap / duplicate `act`** (the same action sent twice before the first state arrives). Expected: applied once, then `ack` for the first and `reject notYourTurn` for the second; `seq` and the log advance by exactly one. Test: Task 9 "a duplicate act is applied once".
5. **D1 unavailable when a game ends.** Expected: the game still finishes and broadcasts `gameWon` and `room.status = 'finished'`; the failure is only logged. Test: Task 7 "saveGameSafely swallows D1 failures" (`Room` always goes through `saveGameSafely`).

```ts
import type { Action, GameEvent, PlayerId, PlayerView } from '@tysiac/engine';

export const PROTOCOL_VERSION = 1;

// ---------- HTTP ----------
// POST /api/rooms            body CreateRoomRequest → CreateRoomResponse | { error: string }
export interface CreateRoomRequest { maxPlayers: 3 | 4; playerId: PlayerId; name: string; avatar: string }
export interface CreateRoomResponse { code: string }
// GET /api/rooms/:code       → RoomExistsResponse   (used by the app before opening a socket)
export interface RoomExistsResponse { exists: boolean; status?: RoomStatus; maxPlayers?: 3 | 4; seatsTaken?: number }
// GET /api/history?player=<id> → HistoryResponse
export interface HistoryGame {
  id: string; finishedAt: number; playerCount: 3 | 4; winnerId: PlayerId;
  players: { id: PlayerId; name: string; avatar: string; isBot: boolean; finalScore: number; won: boolean }[];
}
export interface HeadToHead { opponentId: PlayerId; name: string; avatar: string; games: number; wins: number; losses: number }
export interface LeaderboardRow { playerId: PlayerId; name: string; avatar: string; games: number; wins: number }
export interface HistoryResponse { games: HistoryGame[]; headToHead: HeadToHead[]; leaderboard: LeaderboardRow[] }
// WebSocket: GET /ws/:code (Upgrade: websocket). Max message 4 KB, ≤ 20 msgs/s per socket.

// ---------- client → server ----------
export type ClientMessage =
  | { t: 'hello'; v: typeof PROTOCOL_VERSION; playerId: PlayerId; secret: string; name: string; avatar: string; coach: boolean }
  | { t: 'act'; id: string; action: Action }
  | { t: 'lobby'; op: LobbyOp }
  | { t: 'botFor'; playerId: PlayerId }     // allowed when that seat has been away ≥ 30 s
  | { t: 'setCoach'; coach: boolean }
  | { t: 'rematch' }                         // host only, when status === 'finished'
  | { t: 'leave' }                           // lobby only: frees your seat
  | { t: 'ping' };

export type LobbyOp =
  | { op: 'addBot' }                                 // host
  | { op: 'removeBot'; playerId: PlayerId }          // host
  | { op: 'swapSeats'; a: number; b: number }        // anyone (seat indices, clockwise)
  | { op: 'setFirstDealer'; seat: number }           // host
  | { op: 'start' };                                 // host, all seats filled

// ---------- server → client ----------
export type RoomStatus = 'lobby' | 'playing' | 'finished';

export interface RoomSeat {
  id: PlayerId; name: string; avatar: string; isBot: boolean;
  connected: boolean;           // bots: always true
  awaySince: number | null;     // ms epoch when disconnected during a game
  botFor: boolean;              // a bot is currently playing for this human
  coach: boolean;               // shows 🎓
}

export interface RoomInfo {
  code: string; status: RoomStatus; maxPlayers: 3 | 4; hostId: PlayerId;
  seats: (RoomSeat | null)[];   // length = maxPlayers, clockwise; null = empty seat (lobby only)
  firstDealer: number;
}

export type ServerMessage =
  | { t: 'welcome'; you: PlayerId; room: RoomInfo; serverTime: number }
  | { t: 'room'; room: RoomInfo }
  | { t: 'state'; seq: number; view: PlayerView; events: GameEvent[] }   // events already filtered for this player
  | { t: 'ack'; id: string }
  | { t: 'reject'; id: string; code: string; message: string }
  | { t: 'error'; code: ErrorCode; message: string }
  | { t: 'pong' };

export type ErrorCode = 'badMessage' | 'roomFull' | 'badSecret' | 'notHost' | 'notInRoom' | 'rateLimited' | 'gameInProgress' | 'versionMismatch';

export * from './schemas';
```

- [ ] **Step 6: Write `src/schemas.ts`**

`PROTOCOL_VERSION` is imported **type-only** here. A value import would create an `index ↔ schemas` evaluation cycle, and `PROTOCOL_VERSION` would be read before it is initialised.

```ts
import { z } from 'zod';
import type { ClientMessage, PROTOCOL_VERSION } from './index';

/** Largest accepted client message, in UTF-8 bytes (spec §6). */
export const MAX_MESSAGE_BYTES = 4096;

/** Must equal PROTOCOL_VERSION — the annotation makes tsc fail if they ever diverge. */
const VERSION: typeof PROTOCOL_VERSION = 1;

export const PlayerIdSchema = z.string().min(1).max(64);
const NameSchema = z.string().trim().min(1).max(24);
const AvatarSchema = z.string().min(1).max(16);
const SecretSchema = z.string().min(8).max(128);
const RequestIdSchema = z.string().min(1).max(64);
const SeatIndexSchema = z.int().min(0).max(3);

export const CardSchema = z.strictObject({
  suit: z.enum(['clubs', 'diamonds', 'hearts', 'spades']),
  rank: z.enum(['9', '10', 'J', 'Q', 'K', 'A']),
});

export const ActionSchema = z.discriminatedUnion('type', [
  z.strictObject({ type: z.literal('bid'), amount: z.int().min(100).max(400) }),
  z.strictObject({ type: z.literal('pass') }),
  z.strictObject({ type: z.literal('play') }),
  z.strictObject({ type: z.literal('throw') }),
  z.strictObject({
    type: z.literal('handout'),
    to: z.record(PlayerIdSchema, CardSchema).refine((to) => Object.keys(to).length <= 3, 'Too many recipients'),
  }),
  z.strictObject({ type: z.literal('card'), card: CardSchema }),
  z.strictObject({ type: z.literal('pause') }),
  z.strictObject({ type: z.literal('resume') }),
]);

export const LobbyOpSchema = z.discriminatedUnion('op', [
  z.strictObject({ op: z.literal('addBot') }),
  z.strictObject({ op: z.literal('removeBot'), playerId: PlayerIdSchema }),
  z.strictObject({ op: z.literal('swapSeats'), a: SeatIndexSchema, b: SeatIndexSchema }),
  z.strictObject({ op: z.literal('setFirstDealer'), seat: SeatIndexSchema }),
  z.strictObject({ op: z.literal('start') }),
]);

export const ClientMessageSchema = z.discriminatedUnion('t', [
  z.strictObject({
    t: z.literal('hello'),
    v: z.literal(VERSION),
    playerId: PlayerIdSchema,
    secret: SecretSchema,
    name: NameSchema,
    avatar: AvatarSchema,
    coach: z.boolean(),
  }),
  z.strictObject({ t: z.literal('act'), id: RequestIdSchema, action: ActionSchema }),

export type ParseResult =
  | { ok: true; msg: ClientMessage }
  | { ok: false; code: 'badMessage' | 'versionMismatch'; message: string };

/** UTF-8 byte length without TextEncoder (keeps this package free of DOM/Node lib types). */
function utf8Length(text: string): number {
  let bytes = 0;
  for (let i = 0; i < text.length; i++) {
    const c = text.charCodeAt(i);
    if (c < 0x80) bytes += 1;
    else if (c < 0x800) bytes += 2;
    else if (c >= 0xd800 && c <= 0xdbff) {
      bytes += 4;
      i++;
    } else bytes += 3;
  }
  return bytes;
}

const bad = (message: string): ParseResult => ({ ok: false, code: 'badMessage', message });

/** Validates one raw WebSocket text frame. Never throws. */
export function parseClientMessage(raw: string): ParseResult {
  if (typeof raw !== 'string') return bad('Messages must be text');
  // UTF-16 length ≤ UTF-8 length, so the cheap check first.
  if (raw.length > MAX_MESSAGE_BYTES || utf8Length(raw) > MAX_MESSAGE_BYTES) return bad('Message too large');
  let json: unknown;
  try {
    json = JSON.parse(raw);
  } catch {
    return bad('Message is not valid JSON');
  }
  if (typeof json === 'object' && json !== null && (json as { t?: unknown }).t === 'hello' && (json as { v?: unknown }).v !== VERSION) {
    return { ok: false, code: 'versionMismatch', message: `This server speaks protocol v${VERSION}` };
  }
  const result = ClientMessageSchema.safeParse(json);
  if (!result.success) return bad(z.prettifyError(result.error).slice(0, 300));
  return { ok: true, msg: result.data satisfies ClientMessage };
}

```ts
/** Room code alphabet: no 0/O, 1/I/L (spec §6). */
export const CODE_ALPHABET = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
export const CODE_LENGTH = 6;

const CODE_RE = new RegExp(`^[${CODE_ALPHABET}]{${CODE_LENGTH}}$`);
/** 8 × 31: bytes at or above this would bias `byte % 31`. */
const UNBIASED_LIMIT = 248;

const cryptoBytes = (n: number): Uint8Array => crypto.getRandomValues(new Uint8Array(n));

export function generateRoomCode(random: (n: number) => Uint8Array = cryptoBytes): string {
  let code = '';
  while (code.length < CODE_LENGTH) {
    for (const byte of random(CODE_LENGTH * 2)) {
      if (byte < UNBIASED_LIMIT && code.length < CODE_LENGTH) code += CODE_ALPHABET[byte % CODE_ALPHABET.length];
    }
  }
  return code;
}

export function normalizeRoomCode(raw: string): string | null {
  const code = raw.trim().toUpperCase();
  return CODE_RE.test(code) ? code : null;
}

const encoder = new TextEncoder();

const toHex = (bytes: Uint8Array): string => [...bytes].map((b) => b.toString(16).padStart(2, '0')).join('');

/** Hex SHA-256. The Room stores sha256(secret) per seat, never the secret itself. */
export async function sha256Hex(text: string): Promise<string> {
  return toHex(new Uint8Array(await crypto.subtle.digest('SHA-256', encoder.encode(text))));
}

/** Constant-time string comparison (length is not secret). */
export function safeEqual(a: string, b: string): boolean {
  const x = encoder.encode(a);
  const y = encoder.encode(b);
  if (x.byteLength !== y.byteLength) return false;
  return crypto.subtle.timingSafeEqual(x, y);
}

export function randomHex(bytes: number): string {
  return toHex(crypto.getRandomValues(new Uint8Array(bytes)));
}

import type { GameEvent } from '@tysiac/engine';

export const BOT_DELAY_MIN_MS = 600;
export const BOT_DELAY_SPREAD_MS = 300;
export const AFTER_TRICK_MS = 1100;
export const AFTER_ROUND_MS = 1500;
export const AWAY_TAKEOVER_MS = 30_000;
export const CLEANUP_AFTER_MS = 7 * 24 * 60 * 60 * 1000;

/** Everything the Room's single alarm must do, as ms-epoch due times. */
export interface Schedule {
  bot: number | null;
  cleanup: number;
}

/**
 * Delay before a bot acts (spec §6): 600–900 ms, +1100 ms if the events that led here include a won
 * trick (let the sweep play), +1500 ms if they include a scored round (let the result sheet show).
 */
export function botDelayMs(events: readonly Pick<GameEvent, 'type'>[], rand: () => number, scale = 1): number {
  let ms = BOT_DELAY_MIN_MS + Math.floor(rand() * (BOT_DELAY_SPREAD_MS + 1));
  if (events.some((e) => e.type === 'trickWon')) ms += AFTER_TRICK_MS;
  if (events.some((e) => e.type === 'roundScored')) ms += AFTER_ROUND_MS;
  return Math.round(ms * scale);
}

export function nextAlarmAt(s: Schedule): number {
  return s.bot === null ? s.cleanup : Math.min(s.bot, s.cleanup);
}

export function canTakeOver(awaySince: number | null, now: number): boolean {
  return awaySince !== null && now - awaySince >= AWAY_TAKEOVER_MS;
}

/** BOT_DELAY_SCALE var: "1" in production, "0.1" in tests. Anything invalid means 1. */
export function parseScale(raw: string | undefined): number {
  if (raw === undefined || raw.trim() === '') return 1;
  const n = Number(raw);
  return Number.isFinite(n) && n >= 0 ? n : 1;
}

export const RATE_WINDOW_MS = 1000;
export const RATE_MAX = 20;

export interface RateBucket {
  start: number;
  count: number;
  warned: boolean;
}

export type RateVerdict = 'ok' | 'warn' | 'drop';

export function newBucket(now: number): RateBucket {
  return { start: now, count: 0, warned: false };
}

/** Fixed 1 s window per socket. Over the limit: one 'warn' (send rateLimited), then 'drop' silently. */
export function checkRate(bucket: RateBucket, now: number): RateVerdict {
  if (now - bucket.start >= RATE_WINDOW_MS) {
    bucket.start = now;
    bucket.count = 0;
    bucket.warned = false;
  }
  bucket.count += 1;
  if (bucket.count <= RATE_MAX) return 'ok';
  if (!bucket.warned) {
    bucket.warned = true;
    return 'warn';
  }
  return 'drop';
}

```ts
import type { PlayerId, Seat } from '@tysiac/engine';
import type { ErrorCode, RoomInfo } from '@tysiac/protocol';
import { safeEqual } from '../identity';
import { canTakeOver } from '../scheduler';
import type { InitRoomRequest, PublicSeatMeta, RoomMeta, SeatMeta } from './types';

export const BOT_NAMES = ['Bot Basia', 'Bot Zenek', 'Bot Halina'] as const;
export const BOT_AVATARS = ['🤖', '🦾', '👾'] as const;

export type Failure = { ok: false; code: ErrorCode; message: string };
export type LobbyResult = { ok: true; meta: RoomMeta } | Failure;
export type ClaimResult = { ok: true; meta: RoomMeta; tookBack: boolean } | Failure;

export interface SeatClaim {
  id: PlayerId;
  name: string;
  avatar: string;
  coach: boolean;
  secretHash: string;
}

const fail = (code: ErrorCode, message: string): Failure => ({ ok: false, code, message });
const done = (meta: RoomMeta): LobbyResult => ({ ok: true, meta });
const copy = (meta: RoomMeta): RoomMeta => structuredClone(meta);

function humanSeat(id: PlayerId, name: string, avatar: string, secretHash: string | null, coach: boolean): SeatMeta {
  return { id, name, avatar, isBot: false, secretHash, awaySince: null, botFor: false, coach };
}

const inLobby = (meta: RoomMeta): Failure | null =>
  meta.status === 'lobby' ? null : fail('gameInProgress', 'The game has already started');
const hostOnly = (meta: RoomMeta, by: PlayerId, what: string): Failure | null =>
  by === meta.hostId ? null : fail('notHost', `Only the host can ${what}`);
const seated = (meta: RoomMeta, by: PlayerId): Failure | null =>
  seatOf(meta, by) ? null : fail('notInRoom', 'You are not seated in this room');
const validSeat = (meta: RoomMeta, i: number): boolean => Number.isInteger(i) && i >= 0 && i < meta.maxPlayers;

export function createMeta(req: InitRoomRequest): RoomMeta {
  const seats: (SeatMeta | null)[] = Array.from({ length: req.maxPlayers }, () => null);
  seats[0] = humanSeat(req.hostId, req.name, req.avatar, null, false);
  return {
    code: req.code, maxPlayers: req.maxPlayers, hostId: req.hostId, status: 'lobby', createdAt: req.now,
    seats, firstDealer: 0, gameId: null, startedAt: null,
  };
}

export function seatOf(meta: RoomMeta, id: PlayerId): SeatMeta | null {
  return meta.seats.find((s) => s?.id === id) ?? null;
}

export function isBotControlled(meta: RoomMeta, id: PlayerId): boolean {
  const seat = seatOf(meta, id);
  return seat !== null && (seat.isBot || seat.botFor);
}

/** hello: reclaim your seat (secret must match; first hello on the host seat sets it) or take a free one. */
export function claimSeat(meta: RoomMeta, claim: SeatClaim): ClaimResult {
  const next = copy(meta);
  const seat = seatOf(next, claim.id);
  if (seat) {
    if (seat.isBot) return fail('badSecret', 'That seat belongs to a bot');
    if (seat.secretHash !== null && !safeEqual(seat.secretHash, claim.secretHash)) {
      return fail('badSecret', 'This player is already signed in on another device');
    }
    seat.secretHash = claim.secretHash;
    if (next.status === 'lobby') {
      seat.name = claim.name;
      seat.avatar = claim.avatar;
    }
    seat.coach = claim.coach;
    const tookBack = seat.botFor;
    seat.awaySince = null;
    seat.botFor = false;
    return { ok: true, meta: next, tookBack };
  }
  if (next.status !== 'lobby') return fail('gameInProgress', 'This game has already started');
  const free = next.seats.indexOf(null);
  if (free < 0) return fail('roomFull', 'This room is full');
  next.seats[free] = humanSeat(claim.id, claim.name, claim.avatar, claim.secretHash, claim.coach);
  return { ok: true, meta: next, tookBack: false };
}

export function addBot(meta: RoomMeta, by: PlayerId, botId: PlayerId): LobbyResult {
  const err = inLobby(meta) ?? hostOnly(meta, by, 'add bots');
  if (err) return err;
  const next = copy(meta);
  const free = next.seats.indexOf(null);
  if (free < 0) return fail('roomFull', 'There is no empty seat');
  const used = new Set(next.seats.map((s) => s?.name));
  const i = Math.max(0, BOT_NAMES.findIndex((name) => !used.has(name)));
  next.seats[free] = {
    id: botId, name: BOT_NAMES[i], avatar: BOT_AVATARS[i], isBot: true,
    secretHash: null, awaySince: null, botFor: false, coach: false,
  };
  return done(next);
}

export function removeBot(meta: RoomMeta, by: PlayerId, playerId: PlayerId): LobbyResult {
  const err = inLobby(meta) ?? hostOnly(meta, by, 'remove bots');
  if (err) return err;
  const next = copy(meta);
  const i = next.seats.findIndex((s) => s?.id === playerId && s.isBot);
  if (i < 0) return fail('badMessage', 'No such bot');
  next.seats[i] = null;
  return done(next);
}

export function swapSeats(meta: RoomMeta, by: PlayerId, a: number, b: number): LobbyResult {
  const err = inLobby(meta) ?? seated(meta, by);
  if (err) return err;
  if (!validSeat(meta, a) || !validSeat(meta, b) || a === b) return fail('badMessage', 'Invalid seats');
  const next = copy(meta);
  [next.seats[a], next.seats[b]] = [next.seats[b], next.seats[a]];
  return done(next);
}

export function setFirstDealer(meta: RoomMeta, by: PlayerId, seat: number): LobbyResult {
  const err = inLobby(meta) ?? hostOnly(meta, by, 'choose the first dealer');
  if (err) return err;
  if (!validSeat(meta, seat)) return fail('badMessage', 'Invalid seat');
  return done({ ...copy(meta), firstDealer: seat });
}

export function setCoach(meta: RoomMeta, by: PlayerId, coach: boolean): LobbyResult {
  const err = seated(meta, by);
  if (err) return err;
  const next = copy(meta);
  seatOf(next, by)!.coach = coach;
  return done(next);
}

export function leaveSeat(meta: RoomMeta, by: PlayerId): LobbyResult {
  const err = inLobby(meta) ?? seated(meta, by);
  if (err) return err;
  const next = copy(meta);
  next.seats = next.seats.map((s) => (s?.id === by ? null : s));
  if (next.hostId === by) {
    const heir = next.seats.find((s) => s !== null && !s.isBot);
    if (heir) next.hostId = heir.id;
  }
  return done(next);
}

function beginGame(meta: RoomMeta, gameId: string, now: number, connected: ReadonlySet<PlayerId>): RoomMeta {
  const next = copy(meta);
  next.status = 'playing';
  next.gameId = gameId;
  next.startedAt = now;
  for (const seat of next.seats) {
    if (seat && !seat.isBot && !connected.has(seat.id)) seat.awaySince = seat.awaySince ?? now;
  }
  return next;
}

export function start(meta: RoomMeta, by: PlayerId, gameId: string, now: number, connected: ReadonlySet<PlayerId>): LobbyResult {
  const err = inLobby(meta) ?? hostOnly(meta, by, 'start the game');
  if (err) return err;
  if (meta.seats.some((s) => s === null)) return fail('badMessage', 'Fill every seat before starting');
  return done(beginGame(meta, gameId, now, connected));
}

export function rematch(meta: RoomMeta, by: PlayerId, gameId: string, now: number, connected: ReadonlySet<PlayerId>): LobbyResult {
  if (meta.status !== 'finished') return fail('badMessage', 'The game is not finished yet');
  const err = hostOnly(meta, by, 'start a rematch');
  if (err) return err;
  const next = beginGame(meta, gameId, now, connected);
  next.firstDealer = (meta.firstDealer + 1) % meta.maxPlayers;
  return done(next);
}

/** Last socket of a human closed. Only meaningful during a game; returns `meta` itself when unchanged. */
export function markAway(meta: RoomMeta, id: PlayerId, now: number): RoomMeta {
  const seat = seatOf(meta, id);
  if (meta.status !== 'playing' || !seat || seat.isBot || seat.awaySince !== null) return meta;
  const next = copy(meta);
  seatOf(next, id)!.awaySince = now;
  return next;
}

export function setBotFor(meta: RoomMeta, by: PlayerId, target: PlayerId, now: number): LobbyResult {
  if (meta.status !== 'playing') return fail('badMessage', 'No game in progress');
  const err = seated(meta, by);
  if (err) return err;
  const seat = seatOf(meta, target);
  if (!seat || seat.isBot) return fail('badMessage', 'No such player');
  if (seat.botFor) return done(meta);
  if (!canTakeOver(seat.awaySince, now)) {
    return fail('badMessage', 'A bot can take over 30 s after a player disconnects');
  }
  const next = copy(meta);
  seatOf(next, target)!.botFor = true;
  return done(next);
}

/** Engine seats in clockwise order. Throws if a seat is empty (callers check `start` first). */
export function engineSeats(meta: RoomMeta): Seat[] {
  const seats = meta.seats.map((s, i) => {
    if (!s) throw new Error(`Seat ${i} is empty`);
    return { id: s.id, name: s.name, avatar: s.avatar, isBot: s.isBot };
  });
  return withBotFlags(seats, meta);
}

/** Mirrors SeatMeta.botFor into engine seats as `botFor: 'bot'` (contract); removes it elsewhere. */
export function withBotFlags(seats: readonly Seat[], meta: RoomMeta): Seat[] {
  return seats.map((s) => {
    const seat: Seat = { id: s.id, name: s.name, avatar: s.avatar, isBot: s.isBot };
    if (seatOf(meta, s.id)?.botFor) seat.botFor = 'bot';
    return seat;
  });
}

export function publicSeat(s: SeatMeta): PublicSeatMeta {
  return { id: s.id, name: s.name, avatar: s.avatar, isBot: s.isBot, awaySince: s.awaySince, botFor: s.botFor, coach: s.coach };
}

```ts
import type { Action, GameState } from '@tysiac/engine';
import type { Schedule } from '../scheduler';
import type { GameOptions, LogEntry, RoomMeta } from './types';

/** Action log cap (spec §6). Replay = createGame(gameOptions) + reduce over the log. */
export const LOG_CAP = 5000;

type Key = 'meta' | 'state' | 'gameOptions' | 'schedule';
type KvRow = { value: string };
type LogRow = { seq: number; at: number; player: string; action: string };

/**
 * Room persistence on the DO's SQLite. All calls are synchronous; writes made in one event without
 * an intervening await are committed atomically by the runtime.
 */
export class RoomStore {
  constructor(private readonly sql: SqlStorage) {}

  /** Read-only check, so looking up a non-existent room never writes storage. */
  exists(): boolean {
    return this.sql.exec("SELECT name FROM sqlite_master WHERE type = 'table' AND name = 'kv'").toArray().length > 0;
  }

  create(): void {
    this.sql.exec('CREATE TABLE IF NOT EXISTS kv (key TEXT PRIMARY KEY, value TEXT NOT NULL)');
    this.sql.exec(
      'CREATE TABLE IF NOT EXISTS log (seq INTEGER PRIMARY KEY, at INTEGER NOT NULL, player TEXT NOT NULL, action TEXT NOT NULL)',
    );
  }

  getMeta(): RoomMeta | null {
    return this.get<RoomMeta>('meta');
  }
  putMeta(meta: RoomMeta): void {
    this.put('meta', meta);
  }

  getState(): GameState | null {
    return this.get<GameState>('state');
  }
  putState(state: GameState): void {
    this.put('state', state);
  }

  getGameOptions(): GameOptions | null {
    return this.get<GameOptions>('gameOptions');
  }
  putGameOptions(options: GameOptions): void {
    this.put('gameOptions', options);
  }

  getSchedule(): Schedule {
    return this.get<Schedule>('schedule') ?? { bot: null, cleanup: 0 };
  }
  putSchedule(schedule: Schedule): void {
    this.put('schedule', schedule);
  }

  appendLog(entry: LogEntry): void {
    this.sql.exec(
      'INSERT OR REPLACE INTO log (seq, at, player, action) VALUES (?, ?, ?, ?)',
      entry.seq, entry.at, entry.player, JSON.stringify(entry.action),
    );
    if (entry.seq > LOG_CAP) this.sql.exec('DELETE FROM log WHERE seq <= ?', entry.seq - LOG_CAP);
  }

  readLog(): LogEntry[] {
    return this.sql
      .exec<LogRow>('SELECT seq, at, player, action FROM log ORDER BY seq')
      .toArray()
      .map((r) => ({ seq: r.seq, at: r.at, player: r.player, action: JSON.parse(r.action) as Action }));
  }

  clearLog(): void {
    this.sql.exec('DELETE FROM log');
  }

  private get<T>(key: Key): T | null {
    const row = this.sql.exec<KvRow>('SELECT value FROM kv WHERE key = ?', key).toArray()[0];
    return row ? (JSON.parse(row.value) as T) : null;
  }

  private put(key: Key, value: unknown): void {
    this.sql.exec(
      'INSERT INTO kv (key, value) VALUES (?, ?) ON CONFLICT(key) DO UPDATE SET value = excluded.value',
      key, JSON.stringify(value),
    );
  }
}

    finishedAt: now,
    winnerId: winner,
    rounds: state.rounds,
    players: state.seats.map((s, seat) => ({
      id: s.id, name: s.name, avatar: s.avatar, seat, isBot: s.isBot,
      finalScore: state.scores[s.id]?.total ?? 0, won: s.id === winner,
    })),
  };
}

export async function recordGame(db: D1Database, g: GameRecord): Promise<void> {
  await db.batch([
    db
      .prepare(
        'INSERT OR IGNORE INTO games (id, room_code, player_count, started_at, finished_at, winner_id, rounds_json) VALUES (?, ?, ?, ?, ?, ?, ?)',
      )
      .bind(g.id, g.roomCode, g.players.length, g.startedAt, g.finishedAt, g.winnerId, JSON.stringify(g.rounds)),
    ...g.players.flatMap((p) => [
      db
        .prepare(
          'INSERT INTO players (id, name, avatar, last_seen) VALUES (?, ?, ?, ?) ' +
            'ON CONFLICT(id) DO UPDATE SET name = excluded.name, avatar = excluded.avatar, last_seen = excluded.last_seen',
        )
        .bind(p.id, p.name, p.avatar, g.finishedAt),
      db
        .prepare('INSERT OR IGNORE INTO game_players (game_id, player_id, seat, is_bot, final_score, won) VALUES (?, ?, ?, ?, ?, ?)')
        .bind(g.id, p.id, p.seat, p.isBot ? 1 : 0, p.finalScore, p.won ? 1 : 0),
    ]),
  ]);
}

export async function getHistory(db: D1Database, playerId: PlayerId): Promise<HistoryResponse> {
  const games = (await db.prepare(GAMES_SQL).bind(playerId).all<GameRow>()).results;
  const ids = games.map((g) => g.id);

    byGame.set(r.game_id, list);
  }

  return {
    games: games.map((g) => ({
      id: g.id, finishedAt: g.finished_at, playerCount: g.player_count === 4 ? 4 : 3, winnerId: g.winner_id,
      players: byGame.get(g.id) ?? [],
    })),
    headToHead: headToHead.map(

      (r): LeaderboardRow => ({ playerId: r.playerId, name: r.name, avatar: r.avatar, games: r.games, wins: r.wins }),
    ),

import { CreateRoomRequestSchema, PlayerIdSchema } from '@tysiac/protocol';
import type { CreateRoomResponse, RoomExistsResponse } from '@tysiac/protocol';
import { generateRoomCode, normalizeRoomCode } from './codes';
import { handleDebug } from './debug';

import { json } from './http';
import { roomStub } from './rooms';

const MAX_BODY_BYTES = 4096;
const CODE_ATTEMPTS = 5;

const is = (parts: string[], ...want: string[]) => parts.length === want.length && want.every((w, i) => w === '*' || parts[i] === w);

/** Only /api/* and /ws/* reach the Worker (assets.run_worker_first); everything else is static. */
export async function route(request: Request, env: Env): Promise<Response> {
  const url = new URL(request.url);
  const parts = url.pathname.split('/').filter(Boolean);
  const method = request.method;
  try {
    if (method === 'POST' && is(parts, 'api', 'rooms')) return await createRoom(request, env);
    if (method === 'GET' && is(parts, 'api', 'rooms', '*')) return await roomExists(parts[2], env);
    if (method === 'GET' && is(parts, 'ws', '*')) return await openSocket(request, parts[1], env);
    if (method === 'GET' && is(parts, 'api', 'history')) return await history(url, env);
    if (method === 'GET' && is(parts, 'api', 'debug', 'rooms', '*')) return await handleDebug(request, parts[3], env);
    return json({ error: 'Not found' }, 404);
  } catch (err) {
    console.error('request failed', { path: url.pathname, error: String(err) });
    return json({ error: 'Internal error' }, 500);
  }
}

async function createRoom(request: Request, env: Env): Promise<Response> {
  const text = await request.text();
  if (new TextEncoder().encode(text).byteLength > MAX_BODY_BYTES) return json({ error: 'Body too large' }, 413);
  let body: unknown;
  try {
    body = JSON.parse(text);
  } catch {
    return json({ error: 'Body must be JSON' }, 400);
  }
  const parsed = CreateRoomRequestSchema.safeParse(body);
  if (!parsed.success) return json({ error: 'Invalid room request' }, 400);
  const { maxPlayers, playerId, name, avatar } = parsed.data;
  for (let attempt = 0; attempt < CODE_ATTEMPTS; attempt++) {
    const code = generateRoomCode();
    const created = await roomStub(env, code).init({ code, maxPlayers, hostId: playerId, name, avatar, now: Date.now() });
    if (created) return json({ code } satisfies CreateRoomResponse);
  }
  return json({ error: 'Could not allocate a room code' }, 503);
}

  if (!code) return json({ exists: false } satisfies RoomExistsResponse);

import { DurableObject } from 'cloudflare:workers';
import type { GameState, PlayerId } from '@tysiac/engine';
import type { RoomExistsResponse } from '@tysiac/protocol';
import { CLEANUP_AFTER_MS, nextAlarmAt, type Schedule } from '../scheduler';
import * as lobby from './lobby';
import { RoomStore } from './storage';
import type { DebugDump, InitRoomRequest, RoomMeta, SocketAttachment } from './types';

const EMPTY_SCHEDULE: Schedule = { bot: null, cleanup: 0 };

/** Which player a socket speaks for (null until its hello is accepted). Survives hibernation. */
export function attachmentOf(ws: WebSocket): SocketAttachment {
  return (ws.deserializeAttachment() as SocketAttachment | null) ?? { playerId: null };
}

/**
 * One Durable Object per room code (SQLite-backed). Uses the WebSocket Hibernation API only; identity
 * lives in socket attachments, everything else in SQLite; a single alarm drives bots and cleanup.
 */
export class Room extends DurableObject<Env> {
  private readonly store: RoomStore;
  private meta: RoomMeta | null = null;
  private state: GameState | null = null;
  private schedule: Schedule = EMPTY_SCHEDULE;

  constructor(ctx: DurableObjectState, env: Env) {
    super(ctx, env);
    this.store = new RoomStore(ctx.storage.sql);
    // Exact-match pings are answered by the runtime without waking the object.
    ctx.setWebSocketAutoResponse(new WebSocketRequestResponsePair('{"t":"ping"}', '{"t":"pong"}'));
    this.load();
  }

  /** (Re)reads the room from SQLite: on construction (after hibernation, eviction, redeploy) and after test patches. */
  load(): void {
    if (!this.store.exists()) {
      this.meta = null;
      this.state = null;
      this.schedule = EMPTY_SCHEDULE;
      return;
    }
    this.meta = this.store.getMeta();
    this.state = this.store.getState();
    this.schedule = this.store.getSchedule();
  }

  // ---------- RPC from the Worker ----------

  async init(req: InitRoomRequest): Promise<boolean> {
    if (this.meta) return false;
    this.store.create();
    this.setMeta(lobby.createMeta(req));
    await this.reschedule(req.now);
    return true;
  }

  async info(): Promise<RoomExistsResponse> {
    const meta = this.meta;
    if (!meta) return { exists: false };
    return { exists: true, status: meta.status, maxPlayers: meta.maxPlayers, seatsTaken: meta.seats.filter((s) => s !== null).length };
  }

  async debugDump(): Promise<DebugDump | null> {
    const meta = this.meta;
    if (!meta) return null;
    return {
      meta: { ...meta, seats: meta.seats.map((s) => s && lobby.publicSeat(s)) },
      state: this.state,
      gameOptions: this.store.getGameOptions(),
      log: this.store.readLog(),
      schedule: this.schedule,
      connected: [...this.connectedIds()],
    };
  }

  async fetch(request: Request): Promise<Response> {
    if (request.headers.get('Upgrade')?.toLowerCase() !== 'websocket') {
      return new Response('Expected a WebSocket upgrade', { status: 426 });
    }
    if (!this.meta) return new Response('Room not found', { status: 404 });
    const pair = new WebSocketPair();
    this.ctx.acceptWebSocket(pair[1]);
    pair[1].serializeAttachment({ playerId: null } satisfies SocketAttachment);
    return new Response(null, { status: 101, webSocket: pair[0] });
  }

  async alarm(): Promise<void> {
    if (!this.meta) return;
    const now = Date.now();
    if (now >= this.schedule.cleanup) return this.destroy();
    await this.ctx.storage.setAlarm(nextAlarmAt(this.schedule));
  }

  // ---------- internals ----------

  private setMeta(meta: RoomMeta): void {
    this.meta = meta;
    this.store.putMeta(meta);
  }

  /** Activity: cleanup moves to now + 7 days; the single alarm is re-armed. */
  private async reschedule(now: number): Promise<void> {
    this.schedule = { bot: null, cleanup: now + CLEANUP_AFTER_MS };
    this.store.putSchedule(this.schedule);
    await this.ctx.storage.setAlarm(nextAlarmAt(this.schedule));
  }

  private async destroy(): Promise<void> {
    for (const ws of this.ctx.getWebSockets()) {
      try {
        ws.close(1001, 'room expired');
      } catch {
        // already closed
      }
    }
    await this.ctx.storage.deleteAlarm();
    await this.ctx.storage.deleteAll();
    this.meta = null;
    this.state = null;
    this.schedule = EMPTY_SCHEDULE;
  }

  private connectedIds(exclude?: WebSocket): Set<PlayerId> {
    const ids = new Set<PlayerId>();
    for (const ws of this.ctx.getWebSockets()) {
      if (ws === exclude || ws.readyState !== WebSocket.READY_STATE_OPEN) continue;
      const id = attachmentOf(ws).playerId;
      if (id !== null) ids.add(id);
    }
    return ids;
  }
}

A bad hello gets `error <code>` and close 1008, where code ∈ `badMessage | versionMismatch | badSecret | roomFull | gameInProgress`. A good hello gets `welcome`, then `state` (events `[]`) if a game exists, and a `room` broadcast to everyone else. A second socket for the same player closes the older one with 4000 "replaced".
  - **Game actions.** `act` → `ack {id}` to the sender and a personalised `state` to every connected player. An illegal act gets `reject {id, code, message}` to the sender only. With no game yet: `reject` with code `notPlaying`.

import { botAction, makeRandom } from '@tysiac/engine';
import type { Action, PlayerView } from '@tysiac/engine';
import type { ClientMessage, RoomInfo, ServerMessage } from '@tysiac/protocol';
import { call, createRoom, ident, type Ident } from './helpers';

export type Msg<T extends ServerMessage['t']> = Extract<ServerMessage, { t: T }>;

export const isMove = (a: Action): boolean => a.type !== 'pause' && a.type !== 'resume';

export function firstMove(view: PlayerView): Action {
  const move = view.legal.find(isMove);
  if (!move) throw new Error(`${view.me} has no move`);
  return move;
}

/** A test-side WebSocket client: buffers every server message; `next` consumes the first match. */
export class Client {
  readonly inbox: ServerMessage[] = [];
  room: RoomInfo | null = null;
  view: PlayerView | null = null;
  closeCode: number | null = null;
  /** When true, plays a bot move (engine botAction) whenever a state says it is this player's turn. */
  autoplay = false;
  private lastPlayedSeq = -1;
  private readonly rand = makeRandom('autoplay');
  private wake: (() => void) | null = null;

  constructor(readonly ws: WebSocket, readonly who: Ident) {
    ws.addEventListener('message', (event) => {
      const msg = JSON.parse(event.data as string) as ServerMessage;
      this.inbox.push(msg);
      if (msg.t === 'welcome' || msg.t === 'room') this.room = msg.room;
      if (msg.t === 'state') {
        this.view = msg.view;
        if (this.autoplay) this.playIfMyTurn();
      }
      this.wake?.();
    });
    ws.addEventListener('close', (event) => {
      this.closeCode = event.code;
      this.wake?.();
    });
  }

  get id(): string {
    return this.who.playerId;
  }

  send(msg: ClientMessage | Record<string, unknown>): void {
    this.ws.send(JSON.stringify(msg));
  }

  sendRaw(text: string): void {
    this.ws.send(text);
  }

  act(action: Action): string {
    const id = crypto.randomUUID();
    this.send({ t: 'act', id, action });
    return id;
  }

  close(): void {
    this.ws.close(1000, 'test');
  }

  async next<T extends ServerMessage['t']>(t: T, pred: (m: Msg<T>) => boolean = () => true, timeoutMs = 5000): Promise<Msg<T>> {
    const deadline = Date.now() + timeoutMs;
    for (;;) {
      const i = this.inbox.findIndex((m) => m.t === t && pred(m as Msg<T>));
      if (i >= 0) return this.inbox.splice(i, 1)[0] as Msg<T>;
      if (Date.now() > deadline) {
        throw new Error(`${this.who.name} timed out waiting for "${t}"; inbox: ${this.inbox.map((m) => m.t).join(',')}`);
      }
      await this.idle(50);
    }
  }

  async closed(timeoutMs = 3000): Promise<number> {
    const deadline = Date.now() + timeoutMs;
    while (this.closeCode === null) {
      if (Date.now() > deadline) throw new Error(`${this.who.name}: socket did not close`);
      await this.idle(50);
    }
    return this.closeCode;
  }

  playIfMyTurn(): void {
    const view = this.view;
    if (!view || view.paused || view.turn !== view.me || view.seq <= this.lastPlayedSeq) return;
    if (!view.legal.some(isMove)) return;
    this.lastPlayedSeq = view.seq;
    this.act(botAction(view, this.rand));
  }

  private idle(ms: number): Promise<void> {
    return new Promise((resolve) => {
      const timer = setTimeout(() => {
        this.wake = null;
        resolve();
      }, ms);
      this.wake = () => {
        clearTimeout(timer);
        this.wake = null;
        resolve();
      };
    });
  }
}

export function helloMsg(who: Ident, coach = false): ClientMessage {
  return { t: 'hello', v: 1, playerId: who.playerId, secret: who.secret, name: who.name, avatar: who.avatar, coach };
}

export async function connect(code: string, who: Ident): Promise<Client> {
  const res = await call(`/ws/${code}`, { headers: { Upgrade: 'websocket' } });
  const ws = res.webSocket;
  if (res.status !== 101 || !ws) throw new Error(`WebSocket upgrade failed with ${res.status}`);
  ws.accept();
  return new Client(ws, who);
}

export async function join(code: string, who: Ident, coach = false): Promise<Client> {
  const client = await connect(code, who);
  client.send(helloMsg(who, coach));
  await client.next('welcome');
  return client;
}

export interface Table {
  code: string;
  host: Client;
  clients: Client[];
}

/** Creates a room (first human is host), seats everyone, adds bots and (unless start === false) starts. */
export async function setupTable(opts: { humans: string[]; bots?: number; maxPlayers?: 3 | 4; start?: boolean }): Promise<Table> {
  const people = opts.humans.map((name) => ident(name));
  const code = await createRoom(people[0], opts.maxPlayers ?? 3);
  const clients: Client[] = [];
  for (const who of people) clients.push(await join(code, who));
  const host = clients[0];
  for (let i = 1; i <= (opts.bots ?? 0); i++) {
    host.send({ t: 'lobby', op: { op: 'addBot' } });
    await host.next('room', (m) => m.room.seats.filter((s) => s?.isBot).length === i);
  }
  if (opts.start !== false) {
    host.send({ t: 'lobby', op: { op: 'start' } });
    for (const c of clients) await c.next('state');
  }
  return { code, host, clients };
}

    this.load();
  }

  /** (Re)reads the room from SQLite: on construction (after hibernation, eviction, redeploy) and after test patches. */
  load(): void {
    if (!this.store.exists()) {
      this.meta = null;
      this.state = null;
      this.schedule = EMPTY_SCHEDULE;
      return;
    }
    this.meta = this.store.getMeta();
    this.state = this.store.getState();
    this.schedule = this.store.getSchedule();
  }

  // ---------- RPC from the Worker ----------

  async init(req: InitRoomRequest): Promise<boolean> {
    if (this.meta) return false;
    this.store.create();
    this.setMeta(lobby.createMeta(req));
    await this.reschedule(req.now);
    return true;
  }

  async info(): Promise<RoomExistsResponse> {
    const meta = this.meta;
    if (!meta) return { exists: false };
    return { exists: true, status: meta.status, maxPlayers: meta.maxPlayers, seatsTaken: meta.seats.filter((s) => s !== null).length };
  }

  async debugDump(): Promise<DebugDump | null> {
    const meta = this.meta;
    if (!meta) return null;
    return {
      meta: { ...meta, seats: meta.seats.map((s) => s && lobby.publicSeat(s)) },
      state: this.state,
      gameOptions: this.store.getGameOptions(),
      log: this.store.readLog(),
      schedule: this.schedule,
      connected: [...this.connectedIds()],
    };
  }

  async fetch(request: Request): Promise<Response> {
    if (request.headers.get('Upgrade')?.toLowerCase() !== 'websocket') {
      return new Response('Expected a WebSocket upgrade', { status: 426 });
    }
    if (!this.meta) return new Response('Room not found', { status: 404 });
    const pair = new WebSocketPair();
    this.ctx.acceptWebSocket(pair[1]);
    pair[1].serializeAttachment({ playerId: null } satisfies SocketAttachment);
    return new Response(null, { status: 101, webSocket: pair[0] });
  }

  async alarm(): Promise<void> {
    if (!this.meta) return;
    const now = Date.now();
    if (now >= this.schedule.cleanup) return this.destroy();
    await this.ctx.storage.setAlarm(nextAlarmAt(this.schedule));
  }

  // ---------- sockets ----------

  async webSocketMessage(ws: WebSocket, message: string | ArrayBuffer): Promise<void> {
    const now = Date.now();
    let bucket = this.buckets.get(ws);
    if (!bucket) {
      bucket = newBucket(now);
      this.buckets.set(ws, bucket);
    }
    const verdict = checkRate(bucket, now);
    if (verdict === 'drop') return;
    if (verdict === 'warn') return this.sendError(ws, 'rateLimited', 'Too many messages — slow down');

    const me = attachmentOf(ws).playerId;
    const parsed: ParseResult =
      typeof message === 'string' ? parseClientMessage(message) : { ok: false, code: 'badMessage', message: 'Messages must be text' };
    if (!parsed.ok) {
      this.sendError(ws, parsed.code, parsed.message);
      if (me === null) ws.close(1008, parsed.code);
      return;
    }
    if (!this.meta) {
      this.sendError(ws, 'notInRoom', 'This room no longer exists');
      ws.close(1008, 'notInRoom');
      return;
    }
    if (me === null) {
      if (parsed.msg.t !== 'hello') {
        this.sendError(ws, 'badMessage', 'The first message must be hello');
        ws.close(1008, 'badMessage');
        return;
      }
      return this.onHello(ws, parsed.msg, now);
    }
    return this.dispatch(ws, me, parsed.msg, now);
  }

  async webSocketClose(ws: WebSocket): Promise<void> {
    this.onDisconnect(ws);
    try {
      ws.close();
    } catch {
      // the runtime already completed the close handshake
    }
  }

  async webSocketError(ws: WebSocket): Promise<void> {
    this.onDisconnect(ws);
  }

  private async onHello(ws: WebSocket, msg: Hello, now: number): Promise<void> {
    const secretHash = await sha256Hex(msg.secret);
    const meta = this.meta; // read after the await: another hello may have taken a seat meanwhile
    if (!meta) return;
    const claim = lobby.claimSeat(meta, { id: msg.playerId, name: msg.name, avatar: msg.avatar, coach: msg.coach, secretHash });
    if (!claim.ok) {
      this.sendError(ws, claim.code, claim.message);
      ws.close(1008, claim.code);
      return;
    }
    for (const old of this.socketsOf(msg.playerId)) {
      old.serializeAttachment({ playerId: null } satisfies SocketAttachment); // its close must not mark the player away
      old.close(4000, 'replaced');
    }
    ws.serializeAttachment({ playerId: msg.playerId } satisfies SocketAttachment);
    this.setMeta(claim.meta);
    await this.reschedule(now);
    this.send(ws, { t: 'welcome', you: msg.playerId, room: this.roomInfo(), serverTime: now });
    if (this.state) this.send(ws, { t: 'state', seq: this.state.seq, view: viewFor(this.state, msg.playerId), events: [] });
    this.broadcastRoom(ws);
  }

  private async dispatch(ws: WebSocket, me: PlayerId, msg: ClientMessage, now: number): Promise<void> {
    const meta = this.meta;
    if (!meta) return;
    switch (msg.t) {
      case 'hello':
        return this.sendError(ws, 'badMessage', 'You have already joined');
      case 'act':
        return this.onAct(ws, me, msg.id, msg.action, now);
      case 'lobby':
        return this.onLobby(ws, meta, me, msg.op, now);
      case 'setCoach':
        return this.applyLobby(ws, lobby.setCoach(meta, me, msg.coach), now);
      case 'leave':
        return this.onLeave(ws, meta, me, now);
      case 'ping':
        return this.send(ws, { t: 'pong' });
      case 'botFor':
      case 'rematch':
        return this.sendError(ws, 'badMessage', `"${msg.t}" is not available yet`);
    }
  }

  private async onAct(ws: WebSocket, me: PlayerId, id: string, action: Action, now: number): Promise<void> {
    if (!this.state) return this.send(ws, { t: 'reject', id, code: 'notPlaying', message: 'The game has not started yet' });
    const result = reduce(this.state, me, action, now);
    if (!result.ok) return this.send(ws, { t: 'reject', id, code: result.error.code, message: result.error.message });
    await this.commit(me, action, result.state, result.events, now);
    this.send(ws, { t: 'ack', id });
  }

  private async onLobby(ws: WebSocket, meta: RoomMeta, me: PlayerId, op: LobbyOp, now: number): Promise<void> {
    switch (op.op) {
      case 'addBot':
        return this.applyLobby(ws, lobby.addBot(meta, me, `bot-${randomHex(6)}`), now);
      case 'removeBot':
        return this.applyLobby(ws, lobby.removeBot(meta, me, op.playerId), now);
      case 'swapSeats':
        return this.applyLobby(ws, lobby.swapSeats(meta, me, op.a, op.b), now);
      case 'setFirstDealer':
        return this.applyLobby(ws, lobby.setFirstDealer(meta, me, op.seat), now);
      case 'start':
        return this.startGame(ws, lobby.start(meta, me, crypto.randomUUID(), now, this.connectedIds()), now);
    }
  }

  private async applyLobby(ws: WebSocket, result: lobby.LobbyResult, now: number): Promise<void> {
    if (!result.ok) return this.sendError(ws, result.code, result.message);
    this.setMeta(result.meta);
    await this.reschedule(now);
    this.broadcastRoom();
  }

  /** Shared by start and (Task 12) rematch: new seed, new GameState, fresh log. */
  private async startGame(ws: WebSocket, result: lobby.LobbyResult, now: number): Promise<void> {
    if (!result.ok) return this.sendError(ws, result.code, result.message);
    const options: GameOptions = {
      seed: randomHex(8),
      seats: lobby.engineSeats(result.meta),
      maxPlayers: result.meta.maxPlayers,
      firstDealer: result.meta.firstDealer,
    };
    let state: GameState;
    try {
      state = createGame(options);
    } catch (err) {
      return this.sendError(ws, 'badMessage', `Could not start the game: ${String(err)}`);
    }
    this.setMeta(result.meta);
    this.state = state;
    this.store.putState(state);
    this.store.putGameOptions(options);
    this.store.clearLog();
    await this.reschedule(now);
    this.broadcastRoom();
    this.broadcastState([]);
  }

  private async onLeave(ws: WebSocket, meta: RoomMeta, me: PlayerId, now: number): Promise<void> {
    const result = lobby.leaveSeat(meta, me);
    if (!result.ok) return this.sendError(ws, result.code, result.message);
    ws.serializeAttachment({ playerId: null } satisfies SocketAttachment);
    this.setMeta(result.meta);
    await this.reschedule(now);
    this.broadcastRoom();
    ws.close(1000, 'left');
  }

  private onDisconnect(ws: WebSocket): void {
    const me = attachmentOf(ws).playerId;
    if (me === null || !this.meta) return;
    if (this.socketsOf(me, ws).length > 0) return; // another tab of the same player is still here
    const next = lobby.markAway(this.meta, me, Date.now());
    if (next !== this.meta) this.setMeta(next);
    this.broadcastRoom(ws);
  }

  /** Persist + broadcast one accepted engine action. */
  private async commit(by: PlayerId, action: Action, state: GameState, events: GameEvent[], now: number): Promise<void> {
    this.state = state;
    this.store.putState(state);
    this.store.appendLog({ seq: state.seq, at: now, player: by, action });
    this.broadcastState(events);
    await this.reschedule(now);
  }

  // ---------- internals ----------

  private setMeta(meta: RoomMeta): void {
    this.meta = meta;
    this.store.putMeta(meta);
  }

  /** Activity: cleanup moves to now + 7 days; the single alarm is re-armed. */
  private async reschedule(now: number): Promise<void> {
    this.schedule = { bot: null, cleanup: now + CLEANUP_AFTER_MS };
    this.store.putSchedule(this.schedule);
    await this.ctx.storage.setAlarm(nextAlarmAt(this.schedule));
  }

  private async destroy(): Promise<void> {
    for (const ws of this.ctx.getWebSockets()) {
      try {
        ws.close(1001, 'room expired');
      } catch {
        // already closed
      }
    }
    await this.ctx.storage.deleteAlarm();
    await this.ctx.storage.deleteAll();
    this.meta = null;
    this.state = null;
    this.schedule = EMPTY_SCHEDULE;
  }

  private socketsOf(playerId: PlayerId, exclude?: WebSocket): WebSocket[] {
    return this.ctx
      .getWebSockets()
      .filter((ws) => ws !== exclude && ws.readyState === WebSocket.READY_STATE_OPEN && attachmentOf(ws).playerId === playerId);
  }

  private connectedIds(exclude?: WebSocket): Set<PlayerId> {
    const ids = new Set<PlayerId>();
    for (const ws of this.ctx.getWebSockets()) {
      if (ws === exclude || ws.readyState !== WebSocket.READY_STATE_OPEN) continue;
      const id = attachmentOf(ws).playerId;
      if (id !== null) ids.add(id);
    }
    return ids;
  }

  private roomInfo(exclude?: WebSocket): RoomInfo {
    return lobby.toRoomInfo(this.meta!, this.connectedIds(exclude));
  }

  /** `room` to every joined socket except `exclude` (which is also counted as disconnected). */
  private broadcastRoom(exclude?: WebSocket): void {
    if (!this.meta) return;
    const room = this.roomInfo(exclude);
    for (const ws of this.ctx.getWebSockets()) {
      if (ws !== exclude && attachmentOf(ws).playerId !== null) this.send(ws, { t: 'room', room });
    }
  }

  /** Personalised `state` (own view + events this player may see) to every joined socket. */
  private broadcastState(events: GameEvent[]): void {
    const state = this.state;
    if (!state) return;
    for (const ws of this.ctx.getWebSockets()) {
      const id = attachmentOf(ws).playerId;
      if (id === null) continue;
      this.send(ws, { t: 'state', seq: state.seq, view: viewFor(state, id), events: eventsFor(events, id) });
    }
  }

  private send(ws: WebSocket, msg: ServerMessage): void {
    try {
      ws.send(JSON.stringify(msg));
    } catch {
      // socket closed under us; its close handler deals with presence
    }
  }

  private sendError(ws: WebSocket, code: ErrorCode, message: string): void {
    this.send(ws, { t: 'error', code, message });
  }
}

```ts
import { botAction, legalActions, turnOf, viewFor } from '@tysiac/engine';
import type { Action, GameState, PlayerId } from '@tysiac/engine';
import { isBotControlled } from './lobby';
import type { RoomMeta } from './types';

/** The player a bot must move for right now, or null (paused, finished, or a human's turn). */
export function botActor(state: GameState, meta: RoomMeta): PlayerId | null {
  if (state.paused !== null || state.winner !== null || state.phase === 'gameEnd') return null;
  const actor = turnOf(state);
  return actor !== null && isBotControlled(meta, actor) ? actor : null;
}

/** Engine bot on the actor's own view (no hidden info); falls back to the first legal move. */
export function chooseBotAction(state: GameState, actor: PlayerId, rand: () => number): Action {
  try {
    return botAction(viewFor(state, actor), rand);
  } catch (err) {
    const fallback = legalActions(state, actor).find((a) => a.type !== 'pause' && a.type !== 'resume');
    if (!fallback) throw err;
    return fallback;
  }
}

```ts
import { DurableObject } from 'cloudflare:workers';
import { createGame, eventsFor, reduce, viewFor } from '@tysiac/engine';
import type { Action, GameEvent, GameState, PlayerId } from '@tysiac/engine';
import { parseClientMessage } from '@tysiac/protocol';
import type { ClientMessage, ErrorCode, LobbyOp, ParseResult, RoomExistsResponse, RoomInfo, ServerMessage } from '@tysiac/protocol';
import { randomHex, sha256Hex } from '../identity';
import { checkRate, newBucket, type RateBucket } from '../ratelimit';
import { CLEANUP_AFTER_MS, botDelayMs, nextAlarmAt, parseScale, type Schedule } from '../scheduler';
import { botActor, chooseBotAction } from './bots';
import * as lobby from './lobby';
import { RoomStore } from './storage';
import type { DebugDump, GameOptions, InitRoomRequest, RoomMeta, SocketAttachment } from './types';

type Hello = Extract<ClientMessage, { t: 'hello' }>;

const EMPTY_SCHEDULE: Schedule = { bot: null, cleanup: 0 };

/** Which player a socket speaks for (null until its hello is accepted). Survives hibernation. */
export function attachmentOf(ws: WebSocket): SocketAttachment {
  return (ws.deserializeAttachment() as SocketAttachment | null) ?? { playerId: null };
}

/**
 * One Durable Object per room code (SQLite-backed). Uses the WebSocket Hibernation API only; identity
 * lives in socket attachments, everything else in SQLite; a single alarm drives bots and cleanup.
 */
export class Room extends DurableObject<Env> {
  private readonly store: RoomStore;
  private meta: RoomMeta | null = null;
  private state: GameState | null = null;
  private schedule: Schedule = EMPTY_SCHEDULE;
  /** In-memory only: a hibernation simply resets the windows. */
  private readonly buckets = new WeakMap<WebSocket, RateBucket>();

  constructor(ctx: DurableObjectState, env: Env) {
    super(ctx, env);
    this.store = new RoomStore(ctx.storage.sql);
    // Exact-match pings are answered by the runtime without waking the object.
    ctx.setWebSocketAutoResponse(new WebSocketRequestResponsePair('{"t":"ping"}', '{"t":"pong"}'));
    this.load();
  }

  /** (Re)reads the room from SQLite: on construction (after hibernation, eviction, redeploy) and after test patches. */
  load(): void {
    if (!this.store.exists()) {
      this.meta = null;
      this.state = null;
      this.schedule = EMPTY_SCHEDULE;
      return;
    }
    this.meta = this.store.getMeta();
    this.state = this.store.getState();
    this.schedule = this.store.getSchedule();
  }

  // ---------- RPC from the Worker ----------

  async init(req: InitRoomRequest): Promise<boolean> {
    if (this.meta) return false;
    this.store.create();
    this.setMeta(lobby.createMeta(req));
    await this.reschedule(req.now);
    return true;
  }

  async info(): Promise<RoomExistsResponse> {
    const meta = this.meta;
    if (!meta) return { exists: false };
    return { exists: true, status: meta.status, maxPlayers: meta.maxPlayers, seatsTaken: meta.seats.filter((s) => s !== null).length };
  }

  async debugDump(): Promise<DebugDump | null> {
    const meta = this.meta;
    if (!meta) return null;
    return {
      meta: { ...meta, seats: meta.seats.map((s) => s && lobby.publicSeat(s)) },
      state: this.state,
      gameOptions: this.store.getGameOptions(),
      log: this.store.readLog(),
      schedule: this.schedule,
      connected: [...this.connectedIds()],
    };
  }

  async fetch(request: Request): Promise<Response> {
    if (request.headers.get('Upgrade')?.toLowerCase() !== 'websocket') {
      return new Response('Expected a WebSocket upgrade', { status: 426 });
    }
    if (!this.meta) return new Response('Room not found', { status: 404 });
    const pair = new WebSocketPair();
    this.ctx.acceptWebSocket(pair[1]);
    pair[1].serializeAttachment({ playerId: null } satisfies SocketAttachment);
    return new Response(null, { status: 101, webSocket: pair[0] });
  }

  /** The single alarm: room cleanup, or a due bot move. */
  async alarm(): Promise<void> {
    if (!this.meta) return;
    const now = Date.now();
    if (now >= this.schedule.cleanup) return this.destroy();
    if (this.schedule.bot !== null && now >= this.schedule.bot) {
      this.schedule = { ...this.schedule, bot: null };
      this.store.putSchedule(this.schedule);
      await this.playBot(now); // commits (and reschedules) or leaves bot = null
    }
    await this.ctx.storage.setAlarm(nextAlarmAt(this.schedule));
  }

  // ---------- sockets ----------

  async webSocketMessage(ws: WebSocket, message: string | ArrayBuffer): Promise<void> {
    const now = Date.now();
    let bucket = this.buckets.get(ws);
    if (!bucket) {
      bucket = newBucket(now);
      this.buckets.set(ws, bucket);
    }
    const verdict = checkRate(bucket, now);
    if (verdict === 'drop') return;
    if (verdict === 'warn') return this.sendError(ws, 'rateLimited', 'Too many messages — slow down');

    const me = attachmentOf(ws).playerId;
    const parsed: ParseResult =
      typeof message === 'string' ? parseClientMessage(message) : { ok: false, code: 'badMessage', message: 'Messages must be text' };
    if (!parsed.ok) {
      this.sendError(ws, parsed.code, parsed.message);
      if (me === null) ws.close(1008, parsed.code);
      return;
    }
    if (!this.meta) {
      this.sendError(ws, 'notInRoom', 'This room no longer exists');
      ws.close(1008, 'notInRoom');
      return;
    }
    if (me === null) {
      if (parsed.msg.t !== 'hello') {
        this.sendError(ws, 'badMessage', 'The first message must be hello');
        ws.close(1008, 'badMessage');
        return;
      }
      return this.onHello(ws, parsed.msg, now);
    }
    return this.dispatch(ws, me, parsed.msg, now);
  }

  async webSocketClose(ws: WebSocket): Promise<void> {
    this.onDisconnect(ws);
    try {
      ws.close();
    } catch {
      // the runtime already completed the close handshake
    }
  }

  async webSocketError(ws: WebSocket): Promise<void> {
    this.onDisconnect(ws);
  }

  private async onHello(ws: WebSocket, msg: Hello, now: number): Promise<void> {
    const secretHash = await sha256Hex(msg.secret);
    const meta = this.meta; // read after the await: another hello may have taken a seat meanwhile
    if (!meta) return;
    const claim = lobby.claimSeat(meta, { id: msg.playerId, name: msg.name, avatar: msg.avatar, coach: msg.coach, secretHash });
    if (!claim.ok) {
      this.sendError(ws, claim.code, claim.message);
      ws.close(1008, claim.code);
      return;
    }
    for (const old of this.socketsOf(msg.playerId)) {
      old.serializeAttachment({ playerId: null } satisfies SocketAttachment); // its close must not mark the player away
      old.close(4000, 'replaced');
    }
    ws.serializeAttachment({ playerId: msg.playerId } satisfies SocketAttachment);
    this.setMeta(claim.meta);
    if (claim.tookBack) this.syncBotFlags(); // control returns automatically (spec §6)
    await this.reschedule(now); // drops a pending bot move if it was for this player
    this.send(ws, { t: 'welcome', you: msg.playerId, room: this.roomInfo(), serverTime: now });
    if (this.state) this.send(ws, { t: 'state', seq: this.state.seq, view: viewFor(this.state, msg.playerId), events: [] });
    this.broadcastRoom(ws);
  }

  private async dispatch(ws: WebSocket, me: PlayerId, msg: ClientMessage, now: number): Promise<void> {
    const meta = this.meta;
    if (!meta) return;
    switch (msg.t) {
      case 'hello':
        return this.sendError(ws, 'badMessage', 'You have already joined');
      case 'act':
        return this.onAct(ws, me, msg.id, msg.action, now);
      case 'lobby':
        return this.onLobby(ws, meta, me, msg.op, now);
      case 'botFor':
        return this.onBotFor(ws, meta, me, msg.playerId, now);
      case 'setCoach':
        return this.applyLobby(ws, lobby.setCoach(meta, me, msg.coach), now);
      case 'leave':
        return this.onLeave(ws, meta, me, now);
      case 'ping':
        return this.send(ws, { t: 'pong' });
      case 'rematch':
        return this.sendError(ws, 'badMessage', '"rematch" is not available yet');
    }
  }

  private async onAct(ws: WebSocket, me: PlayerId, id: string, action: Action, now: number): Promise<void> {
    if (!this.state) return this.send(ws, { t: 'reject', id, code: 'notPlaying', message: 'The game has not started yet' });
    const result = reduce(this.state, me, action, now);
    if (!result.ok) return this.send(ws, { t: 'reject', id, code: result.error.code, message: result.error.message });
    await this.commit(me, action, result.state, result.events, now);
    this.send(ws, { t: 'ack', id });
  }

  private async onLobby(ws: WebSocket, meta: RoomMeta, me: PlayerId, op: LobbyOp, now: number): Promise<void> {
    switch (op.op) {
      case 'addBot':
        return this.applyLobby(ws, lobby.addBot(meta, me, `bot-${randomHex(6)}`), now);
      case 'removeBot':
        return this.applyLobby(ws, lobby.removeBot(meta, me, op.playerId), now);
      case 'swapSeats':
        return this.applyLobby(ws, lobby.swapSeats(meta, me, op.a, op.b), now);
      case 'setFirstDealer':
        return this.applyLobby(ws, lobby.setFirstDealer(meta, me, op.seat), now);
      case 'start':
        return this.startGame(ws, lobby.start(meta, me, crypto.randomUUID(), now, this.connectedIds()), now);
    }
  }

  private async onBotFor(ws: WebSocket, meta: RoomMeta, me: PlayerId, target: PlayerId, now: number): Promise<void> {
    const result = lobby.setBotFor(meta, me, target, now);
    if (!result.ok) return this.sendError(ws, result.code, result.message);
    this.setMeta(result.meta);
    this.syncBotFlags();
    await this.reschedule(now);
    this.broadcastRoom();
  }

  private async applyLobby(ws: WebSocket, result: lobby.LobbyResult, now: number): Promise<void> {
    if (!result.ok) return this.sendError(ws, result.code, result.message);
    this.setMeta(result.meta);
    await this.reschedule(now);
    this.broadcastRoom();
  }

  /** Shared by start and (Task 12) rematch: new seed, new GameState, fresh log. */
  private async startGame(ws: WebSocket, result: lobby.LobbyResult, now: number): Promise<void> {
    if (!result.ok) return this.sendError(ws, result.code, result.message);
    const options: GameOptions = {
      seed: randomHex(8),
      seats: lobby.engineSeats(result.meta),
      maxPlayers: result.meta.maxPlayers,
      firstDealer: result.meta.firstDealer,
    };
    let state: GameState;
    try {
      state = createGame(options);
    } catch (err) {
      return this.sendError(ws, 'badMessage', `Could not start the game: ${String(err)}`);
    }
    this.setMeta(result.meta);
    this.state = state;
    this.store.putState(state);
    this.store.putGameOptions(options);
    this.store.clearLog();
    await this.reschedule(now, []);
    this.broadcastRoom();
    this.broadcastState([]);
  }

  private async onLeave(ws: WebSocket, meta: RoomMeta, me: PlayerId, now: number): Promise<void> {
    const result = lobby.leaveSeat(meta, me);
    if (!result.ok) return this.sendError(ws, result.code, result.message);
    ws.serializeAttachment({ playerId: null } satisfies SocketAttachment);
    this.setMeta(result.meta);
    await this.reschedule(now);
    this.broadcastRoom();
    ws.close(1000, 'left');
  }

  private onDisconnect(ws: WebSocket): void {
    const me = attachmentOf(ws).playerId;
    if (me === null || !this.meta) return;
    if (this.socketsOf(me, ws).length > 0) return; // another tab of the same player is still here
    const next = lobby.markAway(this.meta, me, Date.now());
    if (next !== this.meta) this.setMeta(next);
    this.broadcastRoom(ws);
  }

  /** Persist + broadcast one accepted engine action (human or bot), then schedule the next bot move. */
  private async commit(by: PlayerId, action: Action, state: GameState, events: GameEvent[], now: number): Promise<void> {
    this.state = state;
    this.store.putState(state);
    this.store.appendLog({ seq: state.seq, at: now, player: by, action });
    this.broadcastState(events);
    await this.reschedule(now, events);
  }

  private async playBot(now: number): Promise<void> {
    if (!this.state || !this.meta) return;
    const actor = botActor(this.state, this.meta);
    if (actor === null) return;
    const action = chooseBotAction(this.state, actor, Math.random);
    const result = reduce(this.state, actor, action, now);
    if (!result.ok) {
      console.error('bot move rejected', { room: this.meta.code, actor, action, error: result.error });
      return;
    }
    await this.commit(actor, action, result.state, result.events, now);
  }

  /** Mirrors SeatMeta.botFor into the engine seats (engine ignores it; views show it). */
  private syncBotFlags(): void {
    if (!this.state || !this.meta) return;
    this.state = { ...this.state, seats: lobby.withBotFlags(this.state.seats, this.meta) };
    this.store.putState(this.state);
  }

  // ---------- internals ----------

  private setMeta(meta: RoomMeta): void {
    this.meta = meta;
    this.store.putMeta(meta);
  }

  /**
   * Re-arms the single alarm: cleanup 7 days after this activity, plus a bot move when a bot (or
   * bot-for) seat must act. `events` = what just happened (fresh delay per spec §6); null keeps an
   * already pending bot move (hello, botFor, lobby changes).
   */
  private async reschedule(now: number, events: readonly GameEvent[] | null = null): Promise<void> {
    const actor = this.state && this.meta ? botActor(this.state, this.meta) : null;
    let bot: number | null = null;
    if (actor !== null) {
      bot =
        events === null && this.schedule.bot !== null
          ? this.schedule.bot
          : now + botDelayMs(events ?? [], Math.random, parseScale(this.env.BOT_DELAY_SCALE));
    }
    this.schedule = { bot, cleanup: now + CLEANUP_AFTER_MS };
    this.store.putSchedule(this.schedule);
    await this.ctx.storage.setAlarm(nextAlarmAt(this.schedule));
  }

  private async destroy(): Promise<void> {
    for (const ws of this.ctx.getWebSockets()) {
      try {
        ws.close(1001, 'room expired');
      } catch {
        // already closed
      }
    }
    await this.ctx.storage.deleteAlarm();
    await this.ctx.storage.deleteAll();
    this.meta = null;
    this.state = null;
    this.schedule = EMPTY_SCHEDULE;
  }

  private socketsOf(playerId: PlayerId, exclude?: WebSocket): WebSocket[] {
    return this.ctx
      .getWebSockets()
      .filter((ws) => ws !== exclude && ws.readyState === WebSocket.READY_STATE_OPEN && attachmentOf(ws).playerId === playerId);
  }

  private connectedIds(exclude?: WebSocket): Set<PlayerId> {
    const ids = new Set<PlayerId>();
    for (const ws of this.ctx.getWebSockets()) {
      if (ws === exclude || ws.readyState !== WebSocket.READY_STATE_OPEN) continue;
      const id = attachmentOf(ws).playerId;
      if (id !== null) ids.add(id);
    }
    return ids;
  }

  private roomInfo(exclude?: WebSocket): RoomInfo {
    return lobby.toRoomInfo(this.meta!, this.connectedIds(exclude));
  }

  /** `room` to every joined socket except `exclude` (which is also counted as disconnected). */
  private broadcastRoom(exclude?: WebSocket): void {
    if (!this.meta) return;
    const room = this.roomInfo(exclude);
    for (const ws of this.ctx.getWebSockets()) {
      if (ws !== exclude && attachmentOf(ws).playerId !== null) this.send(ws, { t: 'room', room });
    }
  }

  /** Personalised `state` (own view + events this player may see) to every joined socket. */
  private broadcastState(events: GameEvent[]): void {
    const state = this.state;
    if (!state) return;
    for (const ws of this.ctx.getWebSockets()) {
      const id = attachmentOf(ws).playerId;
      if (id === null) continue;
      this.send(ws, { t: 'state', seq: state.seq, view: viewFor(state, id), events: eventsFor(events, id) });
    }
  }

  private send(ws: WebSocket, msg: ServerMessage): void {
    try {
      ws.send(JSON.stringify(msg));
    } catch {
      // socket closed under us; its close handler deals with presence
    }
  }

  private sendError(ws: WebSocket, code: ErrorCode, message: string): void {
    this.send(ws, { t: 'error', code, message });
  }
}

    if (this.meta && events.some((e) => e.type === 'gameWon')) {
      const meta: RoomMeta = { ...this.meta, status: 'finished' };
      this.setMeta(meta); // before the await, so a quick rematch already sees 'finished'
      await saveGameSafely(this.env.DB, gameRecordFrom(meta, state, now)); // never throws (spec §6)
      this.broadcastRoom();
    }
    await this.reschedule(now, events);
  }

#!/usr/bin/env node
// Idempotent production setup + deploy for the `tysiac` Worker (Cloudflare free plan). Steps:
//  1. wrangler must be logged in to ACCOUNT_ID       2. ensure a workers.dev subdomain (API)
//  3. ensure D1 `tysiac` exists, write its id into wrangler.jsonc
//  4. apply D1 migrations remotely                   5. ensure DEBUG_KEY in .secrets.json (gitignored)
//  6. placeholder assets if the app isn't built      7. wrangler deploy --secrets-file  8. live smoke test
import { execFileSync } from 'node:child_process';
import { randomBytes } from 'node:crypto';
import { existsSync, readFileSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';

const ACCOUNT_ID = '28218e648f55d8177931a703d4da7292';
const WORKER_NAME = 'tysiac';
const DB_NAME = 'tysiac';
const ROOT = join(import.meta.dirname, '..');
const WRANGLER = join(ROOT, 'node_modules', '.bin', 'wrangler');
const CONFIG = join(ROOT, 'wrangler.jsonc');
const SECRETS = join(ROOT, '.secrets.json');
const API = `https://api.cloudflare.com/client/v4/accounts/${ACCOUNT_ID}`;
const ENV = { ...process.env, CLOUDFLARE_ACCOUNT_ID: ACCOUNT_ID };

function wrangler(args, { quiet = false } = {}) {
  if (!quiet) console.log(`$ wrangler ${args.join(' ')}`);
  // stdin ignored → wrangler runs non-interactively and takes its default answers.
  return execFileSync(WRANGLER, args, { cwd: ROOT, env: ENV, encoding: 'utf8', stdio: ['ignore', 'pipe', 'inherit'] });
}

function apiToken() {
  const out = JSON.parse(wrangler(['auth', 'token', '--json'], { quiet: true }));
  if (!out.token) throw new Error('`wrangler auth token` returned no token — run `wrangler login` first');
  return out.token;
}

async function api(token, method, path, body) {
  const res = await fetch(`${API}${path}`, {
    method,
    headers: { authorization: `Bearer ${token}`, 'content-type': 'application/json' },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  return res.json();
}

async function ensureSubdomain(token) {
  const current = await api(token, 'GET', '/workers/subdomain');
  if (current.success && current.result?.subdomain) {
    console.log(`workers.dev subdomain: ${current.result.subdomain}`);
    return current.result.subdomain;
  }
  for (const candidate of ['tysiac-1000', 'tysiac-cards', `tysiac-${randomBytes(3).toString('hex')}`]) {
    const put = await api(token, 'PUT', '/workers/subdomain', { subdomain: candidate });
    if (put.success) {
      console.log(`registered workers.dev subdomain: ${put.result.subdomain}`);
      return put.result.subdomain;
    }
    console.warn(`subdomain ${candidate} unavailable: ${JSON.stringify(put.errors)}`);
  }
  throw new Error('could not register a workers.dev subdomain');
}

async function ensureDatabase(token) {
  const find = async () => {
    const list = await api(token, 'GET', `/d1/database?name=${DB_NAME}`);
    if (!list.success) throw new Error(`D1 list failed: ${JSON.stringify(list.errors)}`);
    return list.result.find((d) => d.name === DB_NAME);
  };
  let db = await find();
  if (!db) {
    const created = await api(token, 'POST', '/d1/database', { name: DB_NAME });
    if (!created.success) throw new Error(`D1 create failed: ${JSON.stringify(created.errors)}`);
    console.log(`created D1 database ${DB_NAME}`);
    db = await find();
  }
  if (!db?.uuid) throw new Error('D1 database id not found');
  const config = readFileSync(CONFIG, 'utf8');
  const updated = config.replace(/("database_id":\s*")[^"]*(")/, `$1${db.uuid}$2`);
  if (updated !== config) {
    writeFileSync(CONFIG, updated);
    console.log(`wrangler.jsonc: database_id = ${db.uuid}`);
  }
  return db.uuid;
}

function ensureDebugKey() {
  if (existsSync(SECRETS)) {
    const secrets = JSON.parse(readFileSync(SECRETS, 'utf8'));
    if (secrets.DEBUG_KEY) return;
  }
  writeFileSync(SECRETS, `${JSON.stringify({ DEBUG_KEY: randomBytes(24).toString('hex') }, null, 2)}\n`, { mode: 0o600 });
  console.log(`generated DEBUG_KEY in ${SECRETS} (gitignored)`);
}

async function main() {
  const who = wrangler(['whoami']);
  if (!who.includes(ACCOUNT_ID)) throw new Error(`wrangler is not logged in to account ${ACCOUNT_ID}`);
  const token = apiToken();
  const subdomain = await ensureSubdomain(token);
  await ensureDatabase(token);
  process.stdout.write(wrangler(['d1', 'migrations', 'apply', DB_NAME, '--remote']));
  ensureDebugKey();
  execFileSync(process.execPath, [join(ROOT, 'scripts', 'ensure-local.mjs')], { stdio: 'inherit' });
  const out = wrangler(['deploy', '--secrets-file', SECRETS]);
  process.stdout.write(out);
  const url = out.match(/https:\/\/[a-z0-9-]+\.[a-z0-9-]+\.workers\.dev/)?.[0] ?? `https://${WORKER_NAME}.${subdomain}.workers.dev`;
  execFileSync(process.execPath, [join(ROOT, 'scripts', 'smoke.mjs'), url], { stdio: 'inherit' });
  console.log(`\nLive: ${url}`);
}

main().catch((err) => {
  console.error(err instanceof Error ? err.message : err);
  process.exit(1);
});
```
